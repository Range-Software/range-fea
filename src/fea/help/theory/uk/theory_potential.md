## 1. Теоретичні основи

### 1.1 Основна невідома - поле тиску

Основною невідомою є **тиск** `p` порової рідини в кожному вузлі, у паскалях.
Кожен вузол має один ступінь вільності, тож сітка з `N` вузлами дає систему з `N`
рівнянь - так само дешеву, як теплова чи електростатична модель на тій самій
сітці. Швидкість рідини відновлюється з поля тиску після розв’язання.

Поле тиску, що описується цим рівнянням, визначене лише **з точністю до адитивної
сталої**: додавання однакового значення до тиску всюди не змінює жодної
швидкості. Тому кожна модель потребує щонайменше однієї граничної умови
*Pressure (explicit)*, див. 1.7. Чи розуміти тиск як абсолютний, чи як
надлишковий, вирішує користувач - розв’язувач працює лише з його градієнтом.

### 1.2 Основні рівняння

Розв’язувач реалізує **закон Дарсі** для повільної течії однієї нестисливої
рідини, що заповнює пори жорсткого пористого тіла:

```
v = -( k / mu ) * ( grad(p) - rho * g )
```

разом із законом збереження маси нестисливої рідини

```
div( v ) = 0
```

що разом дає рівняння потенціалу (типу Лапласа) для тиску:

```
div( ( k / mu ) * ( grad(p) - rho * g ) ) = 0
```

| Символ | Значення | Одиниці | Джерело |
|---|---|---|---|
| `p` | тиск порової рідини | `Pa` | розв’язується |
| `v` | швидкість Дарсі (швидкість фільтрації) | `m/s` | відновлюється, див. 1.8 |
| `k` | власна проникність пористого тіла | `m^2` | властивість матеріалу *Permeability to fluids* |
| `mu` | динамічна в’язкість порової рідини | `kg/(m*s)` | властивість матеріалу *Dynamic viscosity* |
| `rho` | густина порової рідини | `kg/m^3` | властивість матеріалу *Density* |
| `g` | прискорення вільного падіння | `m/s^2` | умова навколишнього середовища, див. 1.6 |

Відношення `k/mu` відіграє ту роль, яку в тепловій моделі відіграє
теплопровідність. Без гравітації рівняння є рівнянням Лапласа для тиску, і течія
спрямована прямо вздовж спаду тиску. З гравітацією член `rho*g` змушує рідину в
стані спокою мати гідростатичний градієнт тиску: `grad(p) = rho*g` дає `v = 0`.

**Швидкість є швидкістю Дарсі.** Це об’ємна витрата на одиницю **повного**
перерізу, твердої фази й пор разом, - а не швидкість рідини всередині пор. Середня
швидкість у порах більша на обернену величину пористості `n`:

```
v_pore = v / n
```

Пористість не входить в усталену течію, тому розв’язувач її не потребує і не
приймає. Використовуйте її вручну для оцінки часу проходження.

**Проникність і коефіцієнт фільтрації.** Механіка ґрунтів і гідрогеологія часто
наводять замість власної проникності *коефіцієнт фільтрації* `K` у `m/s` -
коефіцієнт закону Дарсі, записаного для гідравлічного напору. Обидві величини
пов’язані через властивості рідини:

```
k = K * mu / ( rho * |g| )
```

Для води при 20 °C значення `K = 1e-4 m/s` відповідає `k = 1.02e-11 m^2`. Нафтова
інженерія наводить проникність у дарсі: `1 D = 9.869e-13 m^2`.

**Обов’язкові властивості матеріалу.** Задача течії через пористі середовища
потребує **трьох** із них:

| Властивість | Одиниці | Використання |
|---|---|---|
| Permeability to fluids | `m^2` | матриця жорсткості - проникність твердої фази |
| Dynamic viscosity | `kg/(m*s)` | матриця жорсткості - в’язкість **рідини** |
| Density | `kg/m^3` | гравітаційний член - густина **рідини** |

**Густина і в’язкість належать поровій рідині, а не пористому тілу.** Тому
матеріал для цього типу задач описує *насичене* середовище: проникність твердого
скелета та густину й в’язкість рідини, яка його заповнює. Так побудовані
постачані матеріали з назвою *... (water saturated)* (див. 2.3). Матеріал, що
містить об’ємну густину сухого ґрунту, спотворить гідростатичний тиск у
відношенні цих двох густин.

Сутність, у матеріалі якої відсутня будь-яка з трьох властивостей, **не
розв’язується**. Перевірка налаштувань попереджає про це перед запуском
розрахунку. Єдиним винятком є сутність із граничною умовою цього типу задач: вона
включається в систему незалежно від матеріалу, а її проникність тоді просто
дорівнює нулю. Саме так приплив отримує гранична поверхня без матеріалу.

Кожна властивість є таблицею залежно від температури. Задача течії через пористі
середовища сама по собі не має поля температури, тому кожна таблиця обчислюється
при `293.15 K`. Таблиці враховуються лише тоді, коли задача *Heat transfer*,
розміщена раніше в тій самій послідовності, обчислила температури елементів -
так тепліша рідина з меншою в’язкістю тече швидше.

### 1.3 Скінченно-елементна дискретизація

Слабке формулювання рівняння тиску дає для кожного елемента

```
K = INT( B^T * ( k / mu ) * B )                  жорсткість
f = INT( B^T * ( k / mu ) * rho * g )            гравітаційне навантаження
  + INT_S( N^T * v_in )                          приплив через границю
```

де `B` будується з похідних функцій форми, `N` - функції форми, а `v_in` -
швидкість припливу, задана на граничній поверхні. Кожна матриця елемента має
розмір `n x n` для елемента з `n` вузлами. Матриці мас чи ємності немає: течія
усталена, див. 1.10.

**Міри елементів.** Як і всюди в Range FEA, сутності меншої вимірності отримують
геометричну міру, щоб представляти реальні тіла:

| Сутність | Міра | Де задається |
|---|---|---|
| Об’єм | 1 | - |
| Поверхня | товщина поверхні | геометричні властивості сутності |
| Лінія | площа перерізу лінії | геометричні властивості сутності |
| Точка | - | точки не проводять течію |

**Поверхня** з товщиною проводить течію у власній площині - так будується
двовимірна модель (переріз греблі чи водоносного шару). Її гравітаційне
навантаження використовує складову `g`, що лежить у площині поверхні. Поверхня з
**нульовою товщиною** - звичайна гранична поверхня об’ємної моделі - не має
жорсткості й лише приймає приплив.

**Лінія** з перерізом проводить течію вздовж свого напрямку, для одновимірної
моделі колони або труби із заповнювачем. **Точка** нічого не додає. Точковий
елемент, вузол якого не належить жодному іншому обчислюваному елементу, залишає в
матриці порожній рядок - не призначайте пористий матеріал точковим сутностям.

### 1.4 Граничні умови

| Гранична умова | Тип | Застосовується до | Складові |
|---|---|---|---|
| Pressure (explicit) | явна (Діріхле) | поверхня | Pressure `[Pa]` |
| Velocity (inflow) | природна (заданий потік) | поверхня | Velocity `[m/s]` |
| Volumetric flow rate (inflow) | природна (заданий потік) | поверхня | Volumetric flow rate `[m^3/s]` |

Гранична поверхня без жодної з них є **непроникною**: крізь неї не проходить
рідина. Це природна умова рівняння, тому стінки, підошва водоносного шару та
площини симетрії не потребують жодної умови.

**Pressure (explicit)** - єдина явна умова. Кожен вузол поверхні вилучається із
системи рівнянь і утримується при заданому тиску. Це місце, де рідина залишає
модель (вихід, дрена, вільна вода водойми) або входить у неї під відомим тиском.
Кожна модель потребує щонайменше однієї. Щойно призначена умова починається з
`1000 Pa`.

**Velocity (inflow)** задає нормальну швидкість Дарсі крізь поверхню.
**Додатне** значення - приплив у пористе тіло, **від’ємне** - відплив (відбір).
Значення є потоком на одиницю площі, тож повна витрата зростає з площею поверхні.

**Volumetric flow rate (inflow)** задає **повну** витрату крізь поверхню в
`m^3/s`. Розв’язувач ділить її на площу всієї сутності й застосовує результат як
рівномірну швидкість припливу, тож витрата не змінюється при перебудові сітки чи
збільшенні поверхні. Додатне значення знову означає приплив.

Жодна з умов припливу не фіксує тиск: тиск на вході є частиною відповіді. Там, де
поверхня припливу й поверхня з *Pressure (explicit)* мають спільні вузли, у цих
вузлах перемагає тиск.

Поверхня припливу **не потребує ні матеріалу, ні товщини**: сама умова включає її
в систему. Якщо поверхня має пористий матеріал і товщину, вона додатково проводить
течію у власній площині.

Умова *Pressure (implicit)* розв’язувача нестисливої течії для цього типу задач не
пропонується.

Усі складові приймають таблицю залежно від часу, яка діє при ввімкненому
розв’язуванні в часі, див. 1.10.

### 1.5 Гравітація

Гравітація входить через умову навколишнього середовища *Gravitational
acceleration*. **Кожна сутність має її за замовчуванням із
`g = (0, 0, -9.80665) m/s^2`**, тож гравітація спрямована вздовж від’ємної осі Z,
якщо її не змінити. Варто знати два наслідки:

- У моделі, вісь Z якої спрямована вгору, рідина в стані спокою автоматично
  отримує гідростатичний тиск, що зростає на `rho*|g|` на метр глибини. Зазвичай
  саме це й потрібно.
- Модель, побудована з іншою віссю, спрямованою вгору, повинна мати змінену
  умову на кожній пористій сутності, інакше рідина «падає» вбік. Установіть усі
  три складові в нуль, щоб вимкнути гравітацію - наприклад, для горизонтальної
  моделі, у якій цікавить лише різниця тисків.

Гравітація в поєднанні з негоризонтальною поверхнею *Pressure (explicit)* вимагає
уваги: рівномірний тиск на вертикальній грані **не є** гідростатичним, тож біля
цієї грані рідина циркулює. Або задайте тиск залежно від висоти (поділіть грань
на кілька сутностей), або вимкніть гравітацію, якщо вона не є частиною задачі.

### 1.6 Умови навколишнього середовища, початкові умови та зв’язок

#### Умови навколишнього середовища

| Умова навколишнього середовища | Складові | Дія |
|---|---|---|
| Gravitational acceleration | g за X, Y, Z `[m/s^2]` | гравітаційний член закону Дарсі, див. 1.5 |
| Temperature | Temperature `[K]` | пропонується, але не зчитується - див. нижче |

Умова *Temperature* пропонується, бо властивості матеріалу є таблицями залежно від
температури. Розв’язувач її **не зчитує**: температури елементів він бере лише зі
спільних даних, залишених задачею *Heat transfer*, а інакше обчислює кожну
таблицю при `293.15 K`.

#### Початкові умови

| Початкова умова | Дія |
|---|---|
| Pressure | пропонується, не зчитується |
| Velocity | пропонується, не зчитується |

Течія усталена, тож відповідь не залежить від початкового поля, і розв’язувач не
зчитує жодної з початкових умов. Обидві пропонуються, бо цей тип задач поділяє їх
із задачею нестисливої течії.

#### Зв’язок з іншими розв’язувачами

| Напрям | Змінна | Дія |
|---|---|---|
| Тепло -> течія через пористі середовища | Temperature | вибирає рядок кожної залежної від температури таблиці матеріалу |

Тиск і швидкість не використовуються жодним іншим розв’язувачем. Течію через
пористі середовища можна поєднувати з будь-якою іншою фізикою, крім
*Incompressible viscous flow* і *Modal analysis*.

Розв’язувач безумовно повідомляє про збіжність, тож група кроків, що містить лише
задачу течії через пористі середовища, завжди зупиняється після однієї ітерації.

### 1.7 Розв’язання системи

Розв’язувач складає й розв’язує

```
K * p = f
```

`K` симетрична й додатно визначена, щойно задано хоча б один тиск, тому вона
розв’язується методом **спряжених градієнтів** із передобумовленням Якобі.
Складання розпаралелене за елементами з буферами для кожного потоку, які в кінці
один раз об’єднуються, тож результат не залежить від кількості потоків.

Проникності реальних матеріалів сягають від приблизно `1e-9 m^2` (гравій) до
`1e-20 m^2` (непорушена глина), що наблизило б коефіцієнти матриці до меж
округлення ітераційного розв’язувача. Тому перед розв’язанням кожне рівняння
ділиться на найбільше `k/mu` у моделі. Ділення всіх рівнянь на одне й те саме
число не змінює розв’язку; воно лише зберігає добру обумовленість ітерації.

Модель **без граничної умови Pressure (explicit)** не має єдиного розв’язку.
Розв’язувач виявляє це й зупиняється з помилкою *Flow through porous media
requires at least one 'Pressure (explicit)' boundary condition*.

Інші способи отримати вироджену або порожню систему, усі без повідомлень:

- сутність, у матеріалі якої бракує однієї з трьох обов’язкових властивостей, не
  розв’язується, і її вузли випадають із системи;
- сутність із нульовою проникністю або нульовою в’язкістю не має жорсткості, тож
  її вузли залишаються в системі, але ні з чим не з’єднані;
- поверхня з нульовою товщиною або лінія з нульовим перерізом не проводить течію.

### 1.8 Похідні результати

Після розв’язання швидкість елемента відновлюється з вузлового поля тиску.
Градієнт тиску усереднюється за точками інтегрування елемента й поєднується з
гравітаційним членом; для лінійних і поверхневих елементів він повертається в
глобальні координати:

```
v = -( k / mu ) * ( grad(p) - rho * g )
```

| Результат | Застосовується до | Значення |
|---|---|---|
| Pressure `[Pa]` | вузол | розв’язане поле порового тиску |
| Velocity `[m/s]` | елемент | вектор швидкості Дарсі |

Швидкість є **густиною** в тому самому сенсі, що й польові результати інших
розв’язувачів: вона не залежить від розміру елемента, стала в лінійному елементі
й збігається при згущенні сітки. Граничні поверхні з нульовою товщиною показують
нульову швидкість - відображайте результат на об’ємі.

Повна витрата не зберігається як результат. Обчисліть її вручну зі швидкості та
площі перерізу або з умов припливу, див. 5.

Після запису результату журнал розв’язувача виводить статистику обох змінних і
значення в точках моніторингу.

### 1.9 Межі застосовності закону Дарсі

Закон Дарсі справджується для повільної ламінарної течії, у якій сили в’язкості
переважають інерцію рідини. Поширений критерій використовує число Рейнольдса,
утворене із середнього діаметра зерна `d`:

```
Re = rho * |v| * d / mu  <  1 ... 10
```

Течія підземних вод у ґрунтах, фільтрація крізь греблі й насипи, течія крізь
фільтри, засипні шари й більшість пористих технічних матеріалів задовольняють його
з великим запасом. Течія крізь крупний гравій, кам’яну накидку або дуже відкриті
піни при великих швидкостях - ні; тоді закон Дарсі занижує втрату тиску (режим
Форхгеймера), і цей розв’язувач дасть завелику швидкість.

### 1.10 Усталена течія та розв’язування в часі

Тип задач дозволяє розв’язування в часі, але сама течія є **усталеною**: рідина й
пористе тіло нестисливі, і члена ємності немає. При ввімкненому розв’язуванні в
часі кожен крок за часом розв’язує окремий усталений стан зі значеннями умов у цей
момент. Це правильна модель, коли граничні умови змінюються повільно порівняно з
часом, за який установлюється тиск, - рівень водойми над піщаним фільтром, що
змінюється протягом годин, - і вона дозволяє задачі течії через пористі
середовища поділяти послідовність кроків із нестаціонарною тепловою задачею.

Консолідація, осушення ненасиченого ґрунту, течія стисливого газу та будь-яке інше
явище, за якого кількість рідини в порах змінюється з часом, лежать поза моделлю,
див. розділ 6.

## 2. Графічний інтерфейс користувача

Усе потрібне розміщено на панелі **Розв’язувач** (вкладки `Задача`,
`Граничні умови`, `Початкові умови`, `Умови навколишнього середовища`,
`Матеріал`, `Результати`), у меню **Задача** та на панелі **Модель**.

### 2.1 Вибір задачі

`Задача` -> `Послідовність розв’язування задач` (`Ctrl+P`) відкриває діалог
послідовності кроків. Додайте крок і виберіть **Flow through porous media**.

Цей тип задач не можна поєднувати з *Incompressible viscous flow* чи *Modal
analysis*. Крок *Heat transfer*, розміщений перед ним, змушує таблиці матеріалу
стежити за обчисленою температурою.

### 2.2 Вкладка Задача

Вкладка показує групу *Розв’язування в часі*, бо тип задач підтримує
розв’язування в часі - що тут означає нестаціонарний розрахунок, пояснює 1.10.
Течія через пористі середовища не має власної групи налаштувань. Усе
призначається сутностям на вкладках умов.

### 2.3 Вкладка Матеріал

Вкладка `Матеріал` показує матеріал, призначений вибраній сутності. Течія через
пористі середовища потребує **всіх трьох** таких властивостей:

| Властивість | Одиниці | Примітка |
|---|---|---|
| Permeability to fluids | `m^2` | власна проникність твердої фази, див. таблицю нижче |
| Dynamic viscosity | `kg/(m*s)` | порової рідини, `1.003e-3` для води при 20 °C |
| Density | `kg/m^3` | порової рідини, `998.2` для води при 20 °C |

Постачана бібліотека містить готові до використання пористі матеріали, насичені
водою. Кожен містить залежні від температури густину й в’язкість води та типову
проникність:

| Матеріал | Проникність `[m^2]` | Коефіцієнт фільтрації при 20 °C `[m/s]` |
|---|---|---|
| Gravel (water saturated) | `1e-9` | `1e-2` |
| Coarse Sand (water saturated) | `1e-10` | `1e-3` |
| Fine Sand (water saturated) | `1e-12` | `1e-5` |
| Sandstone (water saturated) | `1e-13` | `1e-6` |
| Silt (water saturated) | `1e-14` | `1e-7` |
| Clay (water saturated) | `1e-17` | `1e-10` |

Проникність реального ґрунту може відрізнятися від цих значень на порядок і
більше - це вихідні значення, а не дані конкретної ділянки. Щоб змоделювати іншу
рідину, скопіюйте один із них і замініть густину та в’язкість. Звичайний матеріал
*Sand* - це сухий сипкий матеріал без в’язкості, тому для цього типу задач він
позначений як недійсний.

### 2.4 Вкладка Граничні умови

Вкладка поділена на список доступних граничних умов угорі й редактор вибраної
умови внизу. Спочатку виберіть поверхневу сутність у дереві `Модель`; тоді список
запропонує умови з розділу 1.4. Позначте одну, щоб призначити її, а потім
відредагуйте її складові в нижньому дереві.

- **Pressure (explicit)** утримує тиск на виході. Модель без неї не розв’яжеться.
- **Velocity (inflow)** і **Volumetric flow rate (inflow)** подають у модель
  відому витрату. Додатні значення втікають, від’ємні витікають.
- Поверхні без умови непроникні.

### 2.5 Початкові умови та умови навколишнього середовища

Вкладка `Умови навколишнього середовища` пропонує *Gravitational acceleration*,
яку кожна сутність уже має зі значенням `(0, 0, -9.80665) m/s^2` (див. 1.5), і
*Temperature*, яку цей розв’язувач ігнорує.

Вкладка `Початкові умови` пропонує *Pressure* і *Velocity*, які цей розв’язувач не
зчитує.

### 2.6 Налаштування матричного розв’язувача

`Задача` -> `Налаштувати розв’язувач систем рівнянь` налаштовує ітераційні
розв’язувачі. Розв’язувач течії через пористі середовища використовує пункт
**CG**. Якщо розв’язання не збігається, шукайте спершу сутність із нульовою
проникністю або ізольований точковий елемент, а не налаштування розв’язувача.

### 2.7 Точки моніторингу

`Задача` -> `Визначте точки моніторингу` розміщує зонди в заданих координатах і
вибирає змінну для запису - *Pressure* або *Velocity*. `Звіт` ->
`Пункти моніторингу` показує значення.

### 2.8 Результати та записи

Вкладка `Результати` показує обчислені змінні й керує 3D-переглядом. Тиск є
вузловим скаляром, швидкість - вектором на елементах. Відобразіть швидкість як
векторне поле на об’ємі, щоб побачити шляхи течії.

Вкладка `Записи` панелі `Модель` містить записи результатів: один для усталеного
розрахунку, по одному на кожен вихідний крок за часом при ввімкненому
розв’язуванні в часі.

`Звіт` -> `Файл журналу розв’язувача` показує повний вивід розв’язувача, включно зі
статистикою обох змінних.

## 3. Приклад - течія через піщаний фільтр під дією тиску

**Мета.** Обчислити течію води через горизонтальний піщаний фільтр під дією
відомої різниці тисків і перевірити витрату за законом Дарсі.

Приклад передбачає об’ємну модель прямокутного паралелепіпеда із сіткою -
скористайтеся `Файл` -> `Нова модель`, накресліть паралелепіпед через
`Геометрія` -> `Створити елемент` або імпортуйте геометрію та побудуйте
тетраедричну сітку; приклад *Draw cube* описує це. Позначте обидві торцеві
поверхні як окремі поверхневі сутності, щоб їм можна було призначити умови.

Нехай фільтр має довжину `1 m` уздовж осі X і переріз `0.1 m` на `0.1 m`.

### Крок 1 - вибір задачі

1. `Задача` -> `Послідовність розв’язування задач` (`Ctrl+P`).
2. Додайте крок і виберіть **Flow through porous media**.
3. Підтвердіть кнопкою `OK`.

Залиште *Розв’язування в часі* вимкненим - результатом є один усталений стан.

### Крок 2 - призначення матеріалу

1. Виберіть об’ємну сутність у дереві `Модель`.
2. Відкрийте вкладку `Матеріал` і призначте **Coarse Sand (water saturated)**.

Матеріал містить проникність піску `1e-10 m^2` та густину й в’язкість води.

### Крок 3 - вимкнення гравітації

Фільтр горизонтальний, і цікавить лише різниця тисків, тож приберіть гравітацію за
замовчуванням:

1. Вибравши об’ємну сутність, відкрийте вкладку
   `Умови навколишнього середовища`.
2. Виберіть **Gravitational acceleration** і встановіть усі три складові в `0`.

Якби гравітацію залишили, вода мала б ще й гідростатичний тиск по висоті фільтра
`0.1 m`, а рівномірні тиски на вертикальних торцевих гранях спричинили б її
циркуляцію біля них - див. 1.5.

### Крок 4 - задання обох кінців

1. Виберіть поверхневу сутність у `x = 0`.
2. Відкрийте вкладку `Граничні умови`, позначте **Pressure (explicit)** і задайте
   `10000` Pa - приблизно один метр водяного стовпа.
3. Виберіть поверхневу сутність у `x = 1 m`, позначте **Pressure (explicit)** і
   задайте `0` Pa.

Чотири бічні поверхні не отримують умов: це непроникні стінки.

### Крок 5 - розв’язання

1. `Рішення` -> `Запустити розв’язувач` (`Ctrl+R`).
2. Стежте за перебігом у `Звіт` -> `Файл журналу розв’язувача`.

Розрахунок - це одне розв’язання методом спряжених градієнтів.

### Крок 6 - перегляд результатів

- Вкладка `Результати`: відобразіть **Pressure**. Тиск лінійно спадає від
  `10000` Pa до `0` Pa уздовж фільтра, із пласкими ізобарами, перпендикулярними до
  його осі.
- Відобразіть **Velocity**. Вона спрямована вздовж +X і однакова в кожному
  елементі.
- Точка моніторингу на *Pressure* посередині фільтра показує `5000` Pa.

### Крок 7 - ручний розрахунок

За `k = 1e-10 m^2` і `mu = 1.003e-3 kg/(m*s)` для води при 20 °C:

```
v = ( k / mu ) * dp / L   = 9.97e-8 * 10000 / 1     = 9.97e-4  m/s
Q = v * A                 = 9.97e-4 * 0.01          = 9.97e-6  m^3/s  (0.6 l/min)
```

Результат **Velocity** повинен показати `9.97e-4 m/s`. Число Рейнольдса для зерна
`1 mm` дорівнює `998 * 9.97e-4 * 1e-3 / 1.003e-3 = 1`, на межі режиму Дарсі (1.9).
За пористості `0.35` сама вода рухається зі швидкістю
`9.97e-4 / 0.35 = 2.8e-3 m/s` і проходить фільтр приблизно за шість хвилин.

### Усунення несправностей

| Симптом | Причина |
|---|---|
| *Flow through porous media requires at least one 'Pressure (explicit)' boundary condition* | ніде не задано тиск на виході |
| *Entity has material assigned which is missing required properties* | у матеріалі бракує в’язкості - часто це сухий ґрунтовий матеріал, як-от *Sand* |
| Тиск змінюється з висотою, а швидкість має складову Z | гравітація за замовчуванням досі ввімкнена, див. крок 3 |
| Швидкість усюди нульова | обидва кінці мають однаковий тиск або проникність нульова |

## 4. Приклад - висхідна фільтрація у вертикальній колоні

**Мета.** Протиснути воду вгору через вертикальну піщану колону з відомою витратою
й побачити, як тиск на вході поділяється на гідростатичну частину та частину
тертя.

Використайте паралелепіпед з основою `0.1 m` на `0.1 m` і висотою `1 m` уздовж
осі **Z**, з нижньою поверхнею (`z = 0`) і верхньою поверхнею (`z = 1 m`) як
окремими поверхневими сутностями.

### Крок 1 - задача й матеріал

1. Виберіть **Flow through porous media**, як у прикладі 3.
2. Призначте об’єму **Coarse Sand (water saturated)**.

### Крок 2 - збереження гравітації

Колона стоїть уздовж осі Z, тож гравітація за замовчуванням
`(0, 0, -9.80665) m/s^2` спрямована правильно. Залиште умову *Gravitational
acceleration* без змін.

### Крок 3 - граничні умови

1. Виберіть верхню поверхню, позначте **Pressure (explicit)** і задайте `0` Pa:
   вільна вода над колоною.
2. Виберіть нижню поверхню, позначте **Volumetric flow rate (inflow)** і задайте
   `1e-6` m^3/s. На площі `0.01 m^2` це відповідає швидкості припливу
   `1e-4 m/s`.

Верхня поверхня горизонтальна, тож рівномірний тиск на ній узгоджується з
гравітацією.

### Крок 4 - розв’язання й перегляд

`Рішення` -> `Запустити розв’язувач` (`Ctrl+R`), потім відобразіть **Pressure** і
**Velocity**.

- Швидкість дорівнює `1e-4 m/s` угору (+Z) у кожному елементі.
- Тиск лінійно зростає від `0` Pa вгорі до максимуму на дні.

### Крок 5 - розкладання тиску на вході

Тиск на дні має підняти водяний стовп і протиснути його крізь пісок:

```
p_hydrostatic = rho * g * L            = 998.2 * 9.80665 * 1       = 9789 Pa
p_friction    = mu * v * L / k         = 1.003e-3 * 1e-4 * 1 / 1e-10 = 1003 Pa
p_bottom      = p_hydrostatic + p_friction                         = 10792 Pa
```

Точка моніторингу на нижній поверхні підтверджує суму. Установіть витрату в нуль і
розв’яжіть знову: швидкість зникає, а тиск на дні падає до суто гідростатичних
`9789 Pa` - розв’язувач точно відтворює рідину в стані спокою.

Збільшуйте витрату, доки частина тертя не досягне ваги піску у зваженому стані,
приблизно `(rho_s - rho) * g * (1 - n) * L`: це початок флюїдизації (пливуна),
яку жорсткий скелет цієї моделі не може відтворити - розв’язувач просто обчислює
дедалі більший тиск.

### Усунення несправностей

| Симптом | Причина |
|---|---|
| Тиск на дні - лише частина тертя | гравітацію на об’ємі вимкнено |
| Тиск на дні - лише гідростатична частина | приплив задано не на тій поверхні або його значення нульове |
| Швидкість спрямована вбік | колону побудовано вздовж іншої осі, ніж Z; змініть умову гравітації |

## 5. Перевірка моделі

**Однорідна колона.** Для тіла довжиною `L`, що утримується при `p1` і `p2` на
двох протилежних гранях, з одного матеріалу та з вимкненою гравітацією, тиск
уздовж тіла лінійний і

```
p(x) = p1 + ( p2 - p1 ) * x / L
v    = ( k / mu ) * ( p1 - p2 ) / L
```

Результат швидкості має збігатися з точністю до допуску розв’язувача, а тиск у
серединній площині має бути середнім двох заданих значень.

**Гідростатика.** Тіло з гравітацією, з умовою *Pressure (explicit)* лише на
горизонтальній верхній грані та непроникними стінками в решті місць, повинно
показати нульову швидкість і тиск, що зростає на `rho*|g|` на метр глибини. Це
одночасно перевіряє густину й умову гравітації.

**Баланс витрати.** В усталеній моделі вся рідина, що втікає, повинна витікати.
Для припливу, заданого через *Volumetric flow rate (inflow)*, швидкість у перерізі,
помножена на його площу, повинна дати задану витрату. Зчитайте швидкість у колоні
точкою моніторингу.

**Послідовні шари.** Для двох шарів довжиною `L1`, `L2` і проникністю `k1`, `k2`,
розміщених послідовно між двома заданими тисками, течія чинить опір, як два
послідовні резистори:

```
v  = ( p1 - p2 ) / ( mu * ( L1 / k1 + L2 / k2 ) )
pi = p1 - v * mu * L1 / k1          тиск на межі шарів
```

На відміну від електростатичного розв’язувача, цей ділить тиск пропорційно
**проникностям**, як це зробила б мережа резисторів.

**Радіальна течія до свердловини.** Для напірного водоносного шару товщиною `H`
між свердловиною радіусом `rw`, що утримується при `pw`, і зовнішнім радіусом `R`,
що утримується при `pR`, тиск логарифмічний, а дебіт свердловини дорівнює

```
p(r) = pw + ( pR - pw ) * ln( r / rw ) / ln( R / rw )
Q    = 2 * pi * H * ( k / mu ) * ( pR - pw ) / ln( R / rw )
```

Це перевіряє розв’язувач на неоднорідному полі й показує, чи достатньо дрібна
сітка біля свердловини.

Згустіть сітку щонайменше один раз і переконайтеся, що тиск збігається, а не
дрейфує.

## 6. Обмеження

- **Усталена, нестислива, однофазна течія.** Члена ємності немає, тож консолідація,
  течія стисливого газу та нестаціонарний відгук напірного водоносного шару не
  моделюються. Нестаціонарний розрахунок - це послідовність усталених станів,
  див. 1.10.
- **Лише повністю насичені середовища.** Немає вільної поверхні (депресійної
  кривої) і ненасиченої зони. Фільтрація крізь насип, рівень ґрунтових вод у якому
  треба знайти, лежить поза моделлю, якщо насичену область не охоплено сіткою
  явно.
- **Жорстке пористе тіло.** Скелет не деформується, тож немає зв’язку з аналізом
  напружень, ефективних напружень, консолідації чи флюїдизації.
- **Ізотропна проникність.** Проникність - скаляр. Шаруваті ґрунти з різною
  горизонтальною й вертикальною проникністю треба моделювати окремими шарами.
- **Лише режим Дарсі.** Інерційна (Форхгеймера) і турбулентна течія в дуже
  крупнозернистих середовищах не моделюється, див. 1.9.
- **Граничні умови лише на поверхнях.** Тиски й припливи задаються на поверхневих
  сутностях; немає поверхні височування, свердловини чи лінійного джерела, ані
  заданого тиску на лінії чи в точці.
- **Немає результату повної витрати.** Витрати крізь переріз треба обчислювати зі
  швидкості вручну.
- **Початкові умови не зчитуються**, а умова навколишнього середовища
  *Temperature* не діє; таблиці матеріалу стежать за температурою лише через
  теплову задачу, розміщену раніше в послідовності кроків.
- **Модель потребує заданого тиску.** Без нього розв’язувач зупиняється з
  помилкою.

## 1. Теоретичні основи

### 1.1 Первинне невідоме – потенціал швидкості

Акустичний вирішувач не визначає тиск безпосередньо. Його основним невідомим є **потенціал швидкості** `phi`, скалярне поле з одиницями `m^2/s`. З нього відновлюються обидві цікаві фізичні величини:

```
u = -grad(phi)                  particle velocity      [m/s]
p = rho * dphi/dt               acoustic pressure      [Pa]
```

Використання потенціалу, а не тиску, має дві практичні переваги. Задача залишається скалярною, навіть якщо швидкість частинки є вектором, а задана швидкість стінки - спосіб опису більшості акустичних джерел - входить як природна гранична умова, а не як обмеження.

Наведені вище знаки (`u = -grad(phi)`, `p = +rho * dphi/dt`) використовуються послідовно в розв’язувачу та в збережених результатах.

### 1.2 Керуюче рівняння

Звук малої амплітуди в спокійній однорідній рідині підкоряється рівнянню затухаючих хвиль для потенціалу швидкості:

```
laplace(phi) - (1/c^2) * d2phi/dt2 - (beta/c^2) * dphi/dt = 0
```

| Символ | Значення | Одиниці | Джерело |
|---|---|---|---|
| `phi` | потенціал швидкості | `m^2/s` | вирішено для |
| `c` | швидкість звуку | `m/s` | матеріальне майно |
| `rho` | щільність рідини | `kg/m^3` | матеріальне майно |
| `beta` | об'ємний (об'ємний) коефіцієнт демпфування | `1/s` | властивість матеріалу, за замовчуванням `0` |

Рівняння є лінійним. Отже, остаточною відповіддю є єдине розв’язання на крок у часі або на частоту – зовнішня нелінійна ітерація не виконується, і `hasConverged()` завжди повідомляє про успіх після розв’язання лінійної системи.

**Швидкість звуку.** `c` можна вказати безпосередньо через властивість матеріалу *Швидкість звуку*. Якщо він відсутній або дорівнює нулю, він визначається на основі об’ємної жорсткості та щільності:

```
c = sqrt(E / rho)
```

, де `E` — властивість матеріалу *Модуль пружності*. Для газу `E` — це адіабатичний об’ємний модуль (`gamma * p0`, приблизно `1.42e5 Pa` для повітря при атмосферному тиску), який разом із `rho = 1.2 kg/m^3` дає знайомий `c = 344 m/s`. Пряме надання `c` зазвичай менш схильне до помилок.

Елементи, які не містять власного матеріалу - наприклад, гранична поверхня, що обмежує сітчастий об'єм - успадковують середні `c` і `rho` обчислюваної області, так що терміни імпедансу та випромінювання оцінюються правильно на них.

### 1.3 Дискретизація скінченних елементів

Множення на вагову функцію `w`, інтегрування по області визначення, застосування теореми розбіжності та множення на `c^2` дає слабку форму

```
c^2 * INT( grad(phi).grad(w) )  +  INT( d2phi/dt2 * w )  +  beta * INT( dphi/dt * w )
    +  SUM_boundaries( (c/zeta) * SURF( dphi/dt * w ) )
    =  c^2 * SURF( v_n * w )
```

, яка після заміни функцій форми елемента `N` стає системою другого порядку

```
M * phi'' + C * phi' + K * phi = f
```

с

| Матриця | Визначення | Коментар |
|---|---|---|
| `M` | `INT( N_m * N_n )` | матриця мас |
| `K` | `c^2 * INT( grad(N_m).grad(N_n) )` | матриця жорсткості |
| `C` | `beta * M + (c/zeta) * SURF( N_m * N_n )` | об'ємне демпфування плюс граничний опір |
| `f` | `c^2 * SURF( v_n * N_m )` | встановлена ​​нормальна швидкість джерела |

`M` і `K` додатні напіввизначені; `C` є додатним напіввизначеним, поки відношення імпедансу `zeta` додатне.

**Міри елементів.** Терміни домену (`M`, `K`, основна частина `C`) масштабуються за геометричним розміром об’єкта, якому вони належать:

| Суб'єкт | Виміряти | Де встановлено |
|---|---|---|
| Обсяг | 1 | - |
| Поверхня | товщина поверхні | геометричні властивості сутності |
| Лінія | площа перетину лінії | геометричні властивості сутності |
| Точка | точковий обсяг | геометричні властивості сутності |

Граничні умови (частина імпедансу `C` та джерело `f`) діють на вимірювання простого елемента - площа поверхні елемента поверхні, довжина елемента лінії, одиниця площі для точкового елемента. Тому поверхня, яка обмежує сітчастий об’єм, вносить лише свої граничні умови, оскільки її товщина за замовчуванням дорівнює нулю.

Точкові елементи не мають точок інтеграції. Їхні внески зосереджені безпосередньо на їх єдиному вузлі, що змушує точкові граничні умови працювати на кінцях одновимірних каналів.

### 1.4 Граничні умови

| Гранична умова | Тип | Застосовується до | Компонент |
|---|---|---|---|
| Потенціал швидкості | явний (Діріхле) | точка, лінія, поверхня | Потенціал `[m^2/s]` |
| Швидкість | природний (джерело) | точка, лінія, поверхня | Швидкість `[m/s]` |
| Поглинаюча межа | природні (затухання) | точка, лінія, поверхня | Коефіцієнт акустичного поглинання `[-]` |
| Акустичний опір | природні (затухання) | точка, лінія, поверхня | Акустичний опір `[Pa*s/m]` |

**Швидкість.** Класичне джерело звуку: поверхня, яка вібрує із заданою нормальною швидкістю, наприклад конус гучномовця або поршень. Додатне значення рухає рідину, тобто вона вказує *в* акустичну область. Він входить у праву сторону як `f = c^2 * SURF(v_n * N)`.

Вузол без граничних умов взагалі є ідеальною **жорсткою стіною** - природним умовою слабкої форми є нульова нормальна швидкість. Щоб отримати порожнину з твердою стінкою, нічого не потрібно призначати.

**Акустичний опір.** Визначає відношення тиску до зовнішньої нормальної швидкості частинки на межі, `p = Z * u_n`. Внутрішньо це виражається через безрозмірне **відношення питомого опору**

```
zeta = Z / (rho * c)
```

та вносить внесок у матрицю граничного демпфування `(c/zeta) * SURF(N_m * N_n)`. `Z = rho*c` (`zeta = 1`) є характеристичним імпедансом рідини і дає ідеальне невідбиваюче закінчення. Для повітря в кімнатних умовах `rho*c` близький до `415 Pa*s/m`, що є значенням, яке пропонує гранична умова за замовчуванням.

**Межа поглинання.** Той самий термін, але параметризований **коефіцієнтом поглинання** `alpha` у `[0, 1]`, що вказується в описі матеріалів. Він перетворюється на коефіцієнт імпедансу через коефіцієнт відбиття плоскої хвилі `R = (zeta - 1) / (zeta + 1)` і `alpha = 1 - |R|^2`:

```
zeta = (1 + sqrt(1 - alpha)) / (1 - sqrt(1 - alpha))
```

| `alpha` | `zeta` | Поведінка |
|---|---|---|
| `1.0` | `1` | повністю поглинає, безехове завершення, без відображення |
| `0.5` | `5.83` | частково поглинаючи |
| `0.1` | `38.0` | слабовсмоктуюча |
| `0.0` | нескінченний | жорстка стінка, без амортизації взагалі |

Використовуйте `alpha = 1` на будь-якому штучному розрізі необмеженої області, щоб імітувати вільне випромінювання, і виміряний `alpha` на облицьованій стіні. Якщо умова *Акустичний опір* і *Поглинаюча межа* призначені одній сутності, імпеданс виграє.

### 1.5 Початкові умови

| Початковий стан | Набори | Коментар |
|---|---|---|
| Потенціал швидкості | `phi` при `t = 0` | рідко не нульовий сам по собі |
| Потенціал швидкості/с | `dphi/dt` при `t = 0` | це те, що встановлює початковий **тиск**, `p = rho * dphi/dt` |

Обидва застосовуються лише на першому часовому кроці. Щоб розпочати перехідний процес із зони тиску, призначте *Потенціал швидкості / с* `= p0 / rho` цій сутності. Початкові умови не впливають на гармонічний аналіз.

### 1.6 Аналіз перехідних процесів

Система другого порядку інтегрована зі схемою **Newmark** за допомогою `gamma = 1/2` і

```
beta_N = max( time-march approximation coefficient / 2 , 1/4 )
```

Затискач гарантує `beta_N >= 1/4`, тобто принаймні безумовно стабільний варіант середнього прискорення, і запобігає діленню на нуль для прямого наближення, коефіцієнт якого дорівнює `0`.

Кожен крок вирішує

```
( K + a0*M + a1*C ) * phi_n+1 = f + M*(a0*phi_n + a2*phi'_n + a3*phi''_n)
                                  + C*(a1*phi_n + a4*phi'_n + a5*phi''_n)
```

зі звичайними коефіцієнтами

```
a0 = 1/(beta_N*dt^2)   a1 = gamma/(beta_N*dt)   a2 = 1/(beta_N*dt)
a3 = 1/(2*beta_N) - 1  a4 = gamma/beta_N - 1    a5 = dt/2*(gamma/beta_N - 2)
a6 = dt*(1 - gamma)    a7 = dt*gamma
```

, а потім оновлення стану

```
phi''_n+1 = a0*(phi_n+1 - phi_n) - a2*phi'_n - a3*phi''_n
phi'_n+1  = phi'_n + a6*phi''_n + a7*phi''_n+1
```

Матриця системи є симетричною позитивно визначеною, тому її розв’язують за допомогою методу **спряженого градієнта** та попереднього зумовлення Якобі.

`phi'` і `phi''` записуються у файл результату як *Потенціал / с* і *Potential / s^2*. Вони є станом інтегратора часу, тому вони повинні бути присутніми для перезапуску або для наступного кроку часу, щоб продовжити правильно.

**Для аналізу перехідних процесів потрібен увімкнений розв’язувач часу.** Без нього значення маси та затухання зникають, і задача перетворюється на безглузду задачу Лапласа; розв'язувач повідомляє про це як про помилку, а не створює нісенітницю.

**Вибір кроку за часом.** Схема безумовно стабільна, тому `dt` керується точністю, а не стабільністю. Корисним правилом є визначення найвищої цікавої частоти `f_max` принаймні з 20 кроками на період:

```
dt <= 1 / (20 * f_max)
```

**Вибір сітки.** Розділіть найкоротшу довжину хвилі `lambda_min = c / f_max` принаймні з 10 лінійними елементами:

```
h <= c / (10 * f_max)
```

### 1.7 Гармонічний аналіз

Для стаціонарного відгуку на одній кутовій частоті `omega = 2*pi*f` напишіть `phi(x,t) = Re{ PHI(x) * exp(i*omega*t) }`. Потім `dphi/dt -> i*omega*PHI` і `d2phi/dt2 -> -omega^2*PHI`, і система стає складною задачею **Гельмгольца**

```
( K - omega^2*M + i*omega*C ) * PHI = F
```

Матричні вирішувачі Range FEA є дійсними, тому складна система розв’язується як еквівалентна дійсна блочна система подвійного розміру. З `S = K - omega^2*M` і `D = omega*C`:

```
| S   -D |   | PHI_re |   | F_re |
|        | * |        | = |      |
| D    S |   | PHI_im |   | F_im |
```

Ця блокова матриця є несиметричною та, понад статичну межу, невизначеною, тому її розв’язують за допомогою **GMRES** та попереднього зумовлення Якобі. Перезапущений GMRES стагнує на невизначених системах щоразу, коли простір Крилова набагато менший за систему, тому розв’язувач автоматично розширює перезапуск GMRES до розміру системи, обмеженого фіксованим бюджетом у 256 МБ для двох баз Крилова. Налаштований перезапуск лише збільшується, ніколи не зменшується, і про зміну повідомляється в журналі розв’язувача:

```
Increasing GMRES restart from 10 to 403 for the frequency domain system.
```

Гармонічний аналіз охоплює список частот

```
f_i = first frequency + i * frequency step,   i = 0 .. number of frequencies - 1
```

Кожна частота є незалежним рішенням і створює власний запис результату, так само, як аналіз перехідних процесів створює один запис на крок у часі. Розв’язування в часі не грає ролі; якщо його ввімкнено, він пропускається з попередженням, а його налаштування залишаються недоторканими, щоб перемикання назад до аналізу перехідних процесів не втрачало їх.

### 1.8 Похідні результати

| Результат | Звернутися до | Перехідний | Гармонійний |
|---|---|---|---|
| Потенціал `[m^2/s]` | вузол | `phi(t)` | `Re{PHI}` |
| Потенціал (уявна частина) `[m^2/s]` | вузол | - | `Im{PHI}` |
| Потенціал/с `[m^2/s^2]` | вузол | `dphi/dt` | `omega * abs(PHI)` |
| Потенціал / с^2 `[m^2/s^3]` | вузол | `d2phi/dt2` | `omega^2 * abs(PHI)` |
| Акустичний тиск `[Pa]` | вузол | `rho * dphi/dt`, миттєвий | `omega * rho * abs(PHI)`, амплітуда |
| Акустична фаза `[Deg]` | вузол | - | `arg(P)` |
| Рівень звукового тиску `[dB]` | вузол | `20*log10(abs(p) / p_ref)` | `20*log10(abs(P)/sqrt(2) / p_ref)` |
| Акустична швидкість частинки `[m/s]` | елемент | `-grad(phi)` | амплітуда `-grad(PHI)`, на компонент |
| Акустична інтенсивність `[W/m^2]` | елемент | `p * u`, миттєвий | `0.5 * Re{P * conj(U)}`, усереднений час |

**Рівень звукового тиску** обчислюється відносно *Еталонного тиску* акустичної установки, `2e-5 Pa` за замовчуванням - поріг слуху в повітрі. У гармонічному аналізі використовується середньоквадратичне значення гармонійного сигналу, яке є амплітудою, поділеною на `sqrt(2)`; в аналізі перехідних процесів використовується миттєва величина, тому зареєстрований рівень коливається в межах періоду.

**Акустична інтенсивність** у гармонічному аналізі – це усереднена за часом активна інтенсивність, тобто чистий потік акустичної потужності. Він тотожно дорівнює нулю в чистій стоячій хвилі і дорівнює `0.5 * |p| * |u|` в плоскій біжучої хвилі.

### 1.9 Перехідний чи гармонічний?

| | Перехідний | Гармонійний |
|---|---|---|
| Вирішує | `M*phi'' + C*phi' + K*phi = f` у часі | `(K - w^2*M + i*w*C)*PHI = F` на частоту |
| Відповіді | "що відбувається, коли ..." | "яка стійка відповідь при ..." |
| Збудження | будь-який час історії, включаючи одиничний імпульс | одна синусоїда за раз |
| Вартість | одне розв'язання SPD за крок | одне невизначене рішення подвійного розміру на частоту |
| Записи | один на крок часу | один на частоту |
| Фазова інформація | неявно в історії часу | явний, як поле результату |

**Використовуйте аналіз перехідних процесів для**

- дослідження імпульсної характеристики, відлуння та реверберації;
- перехідні події - удар, закриття клапана, грюк дверей;
- широкосмугове збудження, де один прогін з подальшим перетворенням Фур'є контрольної точки охоплює весь спектр одразу;
- будь-який випадок, коли сама історія часу є відповіддю.

**Використовуйте гармонічний аналіз для**

- функції АЧХ і криві втрат передачі;
- резонанси порожнин і каналів, а також розподіл тиску при резонансі;
- характеристики глушника, глушника та абсорбера в смузі частот;
- карти рівня звукового тиску на один тон;
- будь-який випадок, коли має значення лише стаціонарний стан. Гармонійний цикл зазвичай набагато дешевший, ніж маршування перехідного процесу, достатнього для того, щоб перехідні процеси згасли.

Практичним компромісом є визначення місцезнаходження резонансів за допомогою грубої гармонічної розгортки, а потім уточнення лише цікавої смуги.

## 2. Графічний інтерфейс користувача

Усе, що стосується акустики, знаходиться в доці **Розв’язувач** (вкладки `Problem`, `Boundary conditions`, `Initial conditions`, `Material`, `Results`), меню **Задача** і **Модель**.

### 2.1 Вибір задачі акустики

`Problem` -> `Problem(s) task flow` (`Ctrl+P`) відкриває діалогове вікно розв’язування задач. Додайте завдання та оберіть **Акустика** - «Настроюване хвильове рівняння для вирішення акустичних задач».

Акустика є взаємовиключною з **Хвиля — загальна** і **Модальний аналіз**. Його можна поєднувати з іншими фізиками, і в цьому випадку потік завдань визначає порядок виконання.

### 2.2 Вкладка задачі

Після вибору акустики вкладка `Problem` док-станції Розв’язувач показує два групові поля.

**Розв’язування в часі** - показано, оскільки акустика є задачею, що залежить від часу.

| Поле | Значення |
|---|---|
| Увімкнути | вмикає та вимикає маршування перехідного часу |
| Наближення | апроксимація маршу часу; відображається на Newmark `beta_N`, як описано в 1.6 |
| Час початку | перше значення часу в секундах; ігнорується під час перезапуску вирішувача |
| Час закінчення | `start time + time-step size * number of time-steps`, лише для читання |
| Розмір кроку в часі | `dt` за секунди |
| Кількість часових кроків | скільки кроків обчислити |
| Вихідна частота | записувати файл результатів кожні N кроків; `0` записує лише останній крок |

**Налаштування акустичного аналізу** - групове поле додано для акустики.

| Поле | Значення |
|---|---|
| Тип аналізу | *Перехідний* або *Гармонійний* |
| Перша частота `[Hz]` | перша частота гармонічної розгортки |
| Крок частоти `[Hz]` | приріст між двома послідовними частотами |
| Кількість частот | скільки частот вирішити; кожен створює свій запис |
| Підмітати | мітка лише для читання, яка показує результуючий діапазон частот |
| Еталонний тиск `[Pa]` | використовується для рівня звукового тиску, `2e-5 Pa` за замовчуванням |

Три частотні поля виділені сірим кольором, якщо вибрано *Перехідний*. Еталонний тиск застосовується до обох типів аналізу.

### 2.3 Вкладка Матеріал

На вкладці `Material` перелічено матеріал, призначений вибраній сутності, і властивості матеріалу, які він містить. Для акустики відповідними властивостями є:

| Власність | Одиниці | Необхідно | Коментар |
|---|---|---|---|
| Щільність | `kg/m^3` | так | `rho` |
| Швидкість звуку | `m/s` | один із двох | `c`, використовується безпосередньо, коли ненульовий |
| Модуль пружності | `Pa` | один із двох | запасний варіант, `c = sqrt(E/rho)` |
| Коефіцієнт акустичного демпфування | `1/s` | ні | `beta`, масове ослаблення, `0` за замовчуванням |

Сутність розв’язана акустичним розв’язувачем, якщо вона має щільність **і** або швидкість звуку, або модуль пружності. Оскільки обидва є альтернативами, засіб перевірки налаштувань не повідомляє про відсутність жодного з них; модель, яка не має жодного, відхиляється розв’язувачем із явним повідомленням.

Кожна властивість є таблицею залежно від температури, тому можна ввести залежну від температури швидкість звуку, яка буде інтерпольована, якщо поряд виникає задача теплопередачі.

### 2.4 Вкладка Граничні умови

Вкладка розділена на список менеджера доступних граничних умов угорі та редактор для вибраного нижче. Спочатку виберіть сутність у дереві `Model`; потім менеджер пропонує граничні умови, дійсні для цього типу сутності та для вибраної задачі. Позначте один, щоб призначити його, а потім відредагуйте його компоненти в нижньому дереві.

Для акустики менеджер пропонує:

- **Потенціал швидкості** - явний, точки, лінії та поверхні. Компонент: *Потенціал* `[m^2/s]`.
- **Швидкість** - точки, лінії та поверхні. Компонент: *Швидкість* `[m/s]`.
- **Поглинаюча межа** - точки, лінії та поверхні. Компонент: *Коефіцієнт акустичного поглинання*, безрозмірний, за замовчуванням `1.0`.
- **Акустичний опір** - точки, лінії та поверхні. Компонент: *Акустичний опір* `[Pa*s/m]`, за замовчуванням `415`.

Кожен компонент є таблицею часу, тому джерелу можна надати часову історію: додайте рядки, щоб збільшити швидкість або запустити короткий імпульс. У гармонічному аналізі використовується значення в поточний час розв’язувача, яке для однозначної таблиці є просто цим значенням.

Залиште стіну без будь-яких граничних умов, щоб зробити її акустично жорсткою.

### 2.5 Вкладка початкових умов

Такий самий макет, що й вкладка граничних умов. Для акустики пропонується **Потенціал швидкості** і **Потенціал швидкості / с**. Останній є тим, який задає початкове поле тиску.

### 2.6 Налаштування вирішувача матриць

`Problem` -> `Setup Problem(s) matrix solver` налаштовує ітераційні розв’язувачі. Перехідний акустичний аналіз використовує запис **CG**, гармонічний аналіз використовує запис **GMRES**.

Перезапуск GMRES за замовчуванням для `10` занадто малий для блокової системи частотної області. Розв’язувач підвищує його автоматично, але кількість *зовнішніх* ітерацій і значення збіжності приймаються як налаштовані, тому підвищуйте їх тут, якщо гармонійний цикл не збігається.

### 2.7 Точки моніторингу

`Problem` -> `Define monitoring points` розміщує зонди за заданими координатами та вибирає змінну для запису. Точкою моніторингу *Акустичного тиску* є природний мікрофон: під час перехідного процесу він створює історію тиску в цьому місці, яку можна перевірити за допомогою `Report` -> `Monitoring points`.

### 2.8 Результати

Після запуску вкладка `Results` містить список обчислених змінних і керує тим, що відображає 3D-вид. Акустичні змінні відповідають розділу 1.8.

Вузлові змінні (тиск, рівень звукового тиску, фаза, потенціал) малюються як гладкі поля; змінні елемента (швидкість частинок, інтенсивність) є векторами і найкраще відображаються через векторне поле або розріз.

Вкладка `Records` док-станції `Model` перераховує окремі записи результатів - по одному на часовий крок для перехідного циклу, по одному на частоту для гармонічної розгортки - і дозволяє переходити між ними або анімувати їх.

`Report` -> `Solver log file` показує повний вихід розв’язувача, включаючи блок статистики, надрукований для кожної акустичної змінної після кожного запису.

## 3. Підручник - аналіз перехідних процесів

**Ціль.** Обчислити імпульсну характеристику закритої повітряної порожнини та прочитати історію тиску в положенні мікрофона.

У цьому підручнику передбачається модель сітчастого об’єму. Використовуйте `File` -> `New model`, намалюйте прямокутник за допомогою `Geometry` -> `Create element` або імпортуйте геометрію та тетраедралізуйте її - підручник *Побудова куба* охоплює цю тему.

### Крок 1 - виберіть задачу

1. `Problem` -> `Problem(s) task flow` (`Ctrl+P`).
2. Додайте завдання та виберіть **Акустика**.
3. Підтвердьте за допомогою `OK`.

Вкладка `Problem` док-станції Solver тепер показує групові поля *Розв’язування в часі* і *Налаштування акустичного аналізу*.

### Крок 2 - призначити матеріал

1. Виберіть сутність обсягу в дереві `Model`.
2. Відкрийте вкладку `Material`.
3. Призначте матеріал або створіть його та дайте йому:
   - **Щільність** = `1.2` `kg/m^3`
   - **Швидкість звуку** = `344` `m/s`
4. Залиште **Коефіцієнт затухання звуку** на рівні `0` для незатухаючої порожнини або встановіть його на невелике значення, наприклад `1.0` `1/s`, щоб зменшити відгук.

### Крок 3 - виберіть тип аналізу та часовий крок

1. Відкрийте вкладку `Problem`.
2. У *Налаштуваннях акустичного аналізу* встановіть **Тип аналізу** = `Transient`.
3. У *Вирішувачі часу*:
   - поставте галочку **Включити**;
   - **Час початку** = `0`;
   - **Розмір кроку в часі** = `2e-5` с. Після `dt <= 1/(20*f_max)` це розрізняє частоти приблизно до `2.5 kHz`;
   - **Кількість часових кроків** = `500`, що дає `10 ms` змодельованого часу;
   - **Вихідна частота** = `5`, запис 100 записів результатів.

Перевірте сітку на `h <= c/(10*f_max)`: для `f_max = 2.5 kHz` і `c = 344 m/s` розмір елемента не повинен перевищувати приблизно `14 mm`.

### Крок 4 - збудження порожнини

Два варіанти, виберіть один.

**A - рухома стіна.** Виберіть поверхню, яка представляє джерело, відкрийте вкладку `Boundary conditions` і відзначте **Швидкість**. Введіть історію часу в таблицю компонентів, наприклад короткий імпульс:

| Час `[s]` | Швидкість `[m/s]` |
|---|---|
| `0.0` | `0.0` |
| `0.0002` | `0.01` |
| `0.0004` | `0.0` |
| `0.01` | `0.0` |

**B – початкова область під тиском.** Виберіть об’єкт, який повинен почати під тиском, відкрийте вкладку `Initial conditions` і відзначте **Потенціал швидкості / с**. Введіть `p0 / rho`; для `p0 = 1 Pa` і `rho = 1.2 kg/m^3` це `0.833`.

Залиште будь-яку іншу поверхню без граничної умови, щоб порожнина була твердою, або відзначте **Межа поглинання** з коефіцієнтом поглинання, що відповідає обшивці стіни, щоб дозволити енергії виходити.

### Крок 5 - додайте мікрофон

1. `Problem` -> `Define monitoring points`.
2. Додайте точку в цікавому місці.
3. Виберіть **Акустичний тиск** як його змінну.

### Крок 6 - розв'язати

1. `Solution` -> `Start solver` (`Ctrl+R`).
2. Засіб перевірки налаштування повідомляє про відсутність матеріалів або граничні умови перед початком циклу.
3. Слідкуйте за прогресом у `Report` -> `Solver log file`. Кожен часовий крок друкує збіжність CG і статистику кожної акустичної змінної.

### Крок 7 - перевірте результати

- Док-станція `Model`, вкладка `Records`: переходьте або анімуйте записи часу.
- вкладка `Results`: відображення **Акустичний тиск** або **Рівень звукового тиску** на моделі та **Акустична швидкість частинок** як векторне поле.
- `Report` -> `Monitoring points`: історія тиску на мікрофоні. Його швидкість загасання дає час реверберації; його перетворення Фур'є дає резонанс резонатора.

### Усунення несправностей

| Симптом | Причина |
|---|---|
| *"Перехідний акустичний аналіз потребує ввімкненого вирішувача часу"* | *Увімкнути* не позначено в *Розв’язування в часі*, або тип аналізу має бути *Гармонічний* |
| *"Акустичний розв'язувач вимагає додатного розміру кроку за часом"* | розмір кроку часу дорівнює нулю |
| *"Не знайдено жодного елемента з дійсною швидкістю звуку"* | жодна сутність не має щільності разом із швидкістю звуку чи модулем пружності |
| Відповідь ніколи не слабшає | відсутність демпфування ніде - очікується для ідеально жорсткої порожнини без втрат; додати межу поглинання або коефіцієнт акустичного демпфування |
| Ворушиться попереду хвильового фронту | сітка або часовий крок занадто грубі для вмісту частоти; уточнюйте обидва |

## 4. Підручник - гармонійно-акустичний аналіз

**Мета.** Обчислити частотну характеристику каналу, що закінчується безехово, і карту рівня звукового тиску на кожній частоті.

### Крок 1 - виберіть задачу

`Problem` -> `Problem(s) task flow` (`Ctrl+P`), додайте завдання, виберіть **Акустика**.

### Крок 2 - призначити матеріал

Як у підручнику з перехідними процесами: **Щільність** `1.2 kg/m^3` і **Швидкість звуку** `344 m/s` на рідині.

Розмір сітки для **найвищої** частоти розгортки: `h <= c / (10 * f_max)`.

### Крок 3 - налаштуйте розгортку

Відкрийте вкладку `Problem` і в *Налаштування акустичного аналізу* встановіть:

| Поле | Значення |
|---|---|
| Тип аналізу | `Harmonic` |
| Перша частота | `50` Гц |
| Крок частоти | `50` Гц |
| Кількість частот | `20` |
| Еталонний тиск | `2e-5` Па |

Мітка *Частотна розгортка* підтверджує `50 - 1000 [Hz]`, тобто 20 рішень і 20 записів результатів.

Поле групи *Розв’язування в часі* може залишатися увімкненим - гармонічний аналіз ігнорує його та записує попередження в журнал. Його налаштування збережені.

### Крок 4 - забийте повітропровід

Виберіть вхідну поверхню, відкрийте вкладку `Boundary conditions` і відзначте **Швидкість**. Введіть один рядок із швидкістю поршня, наприклад `0.01` `m/s`. Амплітуда інтерпретується як амплітуда гармонійного збудження на кожній частоті розгортки.

### Крок 5 - завершити канал

Виберіть вихідну поверхню та поставте галочку:

- **Межа поглинання** з **Коефіцієнтом акустичного поглинання** = `1.0` для ідеально невідбиваючого закінчення; або
- **Акустичний опір** з **Акустичний опір** = `rho * c` = `413` `Pa*s/m`, що є одним і тим же, вираженим по-різному.

Використовуйте менший коефіцієнт поглинання, щоб змоделювати частково відбиваючу кінцівку, і залиште вихід без будь-яких умов, щоб змоделювати закритий, жорсткий кінець.

Стінки повітроводу не потребують граничних умов - вони жорсткі за замовчуванням.

### Крок 6 - перевірте розв'язувач матриць

`Problem` -> `Setup Problem(s) matrix solver`, запис **GMRES**. Перезапуск запускається автоматично, але якщо журнал показує застійний залишок, збільште кількість зовнішніх ітерацій і за потреби послабте або збільште значення збіжності.

### Крок 7 - розв'язати

`Solution` -> `Start solver` (`Ctrl+R`). Журнал показує один блок на частоту:

```
Frequency:         1 of 20        | f =  5.000000e+01 [Hz]
{
    Increasing GMRES restart from 10 to ... for the frequency domain system.
    ...
    Acoustic pressure [Pa]
    Sound pressure level [dB]
    ...
}
```

### Крок 8 - перевірте результати

- Док `Model`, вкладка `Records`: один запис на частоту. Перехід через них є розгорткою частоти.
- Вкладка `Results`: відображення **Рівня звукового тиску** для карти децибел, **Акустичний тиск** для амплітуди та **Акустичної фази** для перегляду хвильових фронтів.
- **Інтенсивність звуку** показує, куди надходить акустична потужність. У добре закінченій протоці вона рівномірна і спрямована до вихідного отвору; в резонансній порожнині вона близька до нуля.
- Точка моніторингу на **Акустичний тиск** записує амплітуду на кожній частоті, тобто функцію частотної характеристики в цьому місці.

### Інтерпретація результату

Для прямого повітроводу, що рухається на `v` і завершується безеховою, аналітичний розв’язок плоскої хвилі:

```
|p| = rho * c * v        constant along the duct
|u| = v
|PHI| = v / k            with k = omega / c
I = 0.5 * |p| * |u|
```

Для `rho = 1.2`, `c = 344`, `v = 0.01` це `|p| = 4.13 Pa`, SPL `103.3 dB` та інтенсивність `0.0206 W/m^2`. Відхилення від плоского `|p|` уздовж каналу означають, що завершення є відображенням - або навмисно, або через те, що коефіцієнт поглинання не `1`.

З жорстким закінченням та сама труба стає резонансною. Амплітуда тиску досягає максимуму на чвертьхвильових резонансах `f = (2n+1) * c / (4L)`, а фаза постійна на `+/-90` градусів, з нульовою чистою інтенсивністю.

### Усунення несправностей

| Симптом | Причина |
|---|---|
| *"Гармонійний акустичний аналіз вимагає додатної частоти"* | перша частота дорівнює нулю, а крок частоти дорівнює нулю |
| Залишок застоюється, результати виглядають шумно | GMRES не зійшовся; підвищити зовнішні ітерації в налаштуваннях вирішувача матриць або згрубити сітку |
| Амплітуда роздувається на одній частоті | розгортка потрапила в незатухаючий резонанс; додати межу поглинання або коефіцієнт акустичного демпфування |
| Тиск сильно змінюється вздовж імовірно безехогенної протоки | закінчення відображає; перевірити коефіцієнт поглинання або значення імпедансу |

## 5. Перевірка

Модульний тест `tst_solver_acoustic` (у `range-solver-lib/tests`, створеному з `-DRANGE_BUILD_TESTS=ON`) перевіряє розв’язувач на відповідність рішенням закритої форми на одновимірному каналі `1 m`, дискретизованому 200 елементами ферми, використовуючи налаштування розв’язувача стандартної матриці.

**Гармонійне безехове закінчення** - `rho = 1.2 kg/m^3`, `c = 340 m/s`, `v = 0.01 m/s`, `f = 500 Hz`:

| Кількість | Аналітичний | Обчислений |
|---|---|---|
| Амплітуда тиску | `rho*c*v = 4.0800 Pa` | `4.0800 - 4.0804` на кожному вузлі |
| Амплітуда потенціалу | `v/k = 1.0823e-3 m^2/s` | в межах 1 % |
| Швидкість частинок | `0.01 m/s` | `0.009999 m/s` |
| Рівень звукового тиску | `103.18 dB` | в межах `0.1 dB` |
| Інтенсивність | `0.0204 W/m^2` | в межах 2 % |
| Фазовий градієнт | `k * dx` | в межах 5 градусів |

**Гармонійне, жорстке закінчення** - стояча хвиля дає фазу рівно `+/-90` градусів і нульову чисту інтенсивність, а пікова амплітуда перевищує амплітуду біжучої хвилі.

**Перехідний процес** - збуджена безехово закінчена протока залишається обмеженою, стан Ньюмарка публікується так, що інтеграція продовжується правильно через кроки, а збуджене поле ненульове та скінченне всюди.

## 6. Обмеження

- **Немає структурно-акустичного зв’язку.** Акустику не можна поєднувати з модальним аналізом, а з `RSolverStress` немає інтерфейсу рідина-структура. Вібраційна структура має бути представлена ​​заданою граничною умовою *Швидкість*.
- **Лише лінійна акустика.** Мала амплітуда, спокійне середнє. Ні середнього потоку, ні конвективних ефектів, ні нелінійного поширення.
- **Лише реальний імпеданс.** Граничні умови поглинання та імпедансу приймають реальне значення. Комплексний поверхневий імпеданс, що залежить від частоти, не підтримується.
- **Незалежні від частоти дані про матеріал.** Швидкість звуку та коефіцієнт затухання зведені в таблицю залежно від температури, а не від частоти, тому вони постійні по всій розгортці.
- **Граничні терміни використовують міру простого елемента.** Для одно- чи двовимірної моделі, поперечна площа чи товщина якої не дорівнює `1`, джерело та імпеданс не масштабуються, тоді як доменні умови є. Використовуйте одиницю поперечної площі або повну тривимірну модель, щоб уникнути невідповідності.
- **Гармонійне збудження є реальним.** Задана швидкість входить як дійсна частина комплексного навантаження; джерела з відносним зсувом фази не можуть бути визначені.

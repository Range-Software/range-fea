## 1. Теоретичні основи

### 1.1 Первинне невідоме - поле зміщення

Основним невідомим є **вектор зміщення** `u = (ux, uy, uz)` у кожному вузлі в метрах. Кожен вузол має три ступені свободи, тому сітка з вузлами `N` дає систему рівнянь `3N`. Деформації, напруги та сили реакції відновлюються з поля переміщення після вирішення.

### 1.2 Основні рівняння

Розв’язувач реалізує **лінійну ізотропну пружність із малою деформацією**. Його визначають три відносини.

**Рівновага** тіла при об’ємному навантаженні `b` і поверхневому зчепленні `t`:

```
div(sigma) + b = 0
```

**Відношення деформація-переміщення**, мала деформація:

```
eps_xx = dux/dx        gamma_xy = dux/dy + duy/dx
eps_yy = duy/dy        gamma_yz = duy/dz + duz/dy
eps_zz = duz/dz        gamma_xz = dux/dz + duz/dx
```

**Конститутивне** відношення з тепловим терміном:

```
sigma = D * ( eps - alpha * dT )
```

| Символ | Значення | Одиниці | Джерело |
|---|---|---|---|
| `u` | переміщення | `m` | вирішено для |
| `sigma` | Стрес Коші | `Pa` | відновлений |
| `eps` | інженерна деформація | `-` | відновлений |
| `E` | модуль пружності | `Pa` | матеріальне майно |
| `v` | Коефіцієнт Пуассона | `-` | матеріальне майно |
| `rho` | щільність | `kg/m^3` | матеріальне майно |
| `alpha` | |коефіцієнт теплового розширення | `1/K` | матеріальне майно |
| `dT` | підвищення температури вище безнапруженого стану | `K` | див. 1.5 |

Усі чотири властивості матеріалу є **обов’язковими** – сутність, яка не має жодної з них, не розкривається. Два коефіцієнти демпфування Релея динамічного аналізу (див. 1.7) є необов’язковими.

### 1.3 Матриця пружності

**Елементи об’єму** використовують повну тривимірну ізотропну матрицю пружності в нотації Фойгта з вектором напруги, упорядкованим `[sigma_xx, sigma_yy, sigma_zz, tau_yz, tau_xz, tau_xy]`:

```
        E                | 1-v   v    v      0        0        0     |
D = -----------------  * |  v   1-v   v      0        0        0     |
    (1+v)*(1-2v)         |  v    v   1-v     0        0        0     |
                         |  0    0    0   (1-2v)/2    0        0     |
                         |  0    0    0      0     (1-2v)/2    0     |
                         |  0    0    0      0        0     (1-2v)/2 |
```

**Елементи поверхні** використовують двовимірну форму **площинної деформації** з вектором напруги `[sigma_xx, sigma_yy, tau_xy]`, обчисленим у локальній площині елемента та повернутим назад у глобальні координати:

```
        E                | 1-v   v      0     |
D = -----------------  * |  v   1-v     0     |
    (1+v)*(1-2v)         |  0    0   (1-2v)/2 |
```

Це **деформація** площини, а не напруга площини. Тому тонка пластина, завантажена у власній площині, вийде жорсткішою, ніж передбачила б ідеалізація плоского напруження.

**Лінійні елементи** розглядаються як **ферми**: збирається лише осьова жорсткість `E * A` уздовж напрямку елемента, де `A` є площею перетину лінії. Жорсткість на вигин, зсув або кручення відсутня навіть для типів елементів під назвою «балка».

### 1.4 Дискретизація скінченних елементів

Слабка форма рівноваги дає для кожного елемента

```
K = INT( B^T * D * B )        stiffness matrix
M = INT( rho * N^T * N )      consistent mass matrix
f = load vector, see 1.5
```

де `B` — матриця деформації-переміщення, побудована з похідних функції форми. Матриця кожного елемента є `3n x 3n` для елемента з вузлами `n`, із чергуванням ступенів свободи як `[ux1, uy1, uz1, ux2, uy2, uz2, ...]`.

**Елементні міри.** Як і скрізь у Range FEA, нижчим вимірам надається геометрична міра, щоб вони могли представляти реальні тіла:

| Суб'єкт | Виміряти | Де встановлено |
|---|---|---|
| Обсяг | 1 | - |
| Поверхня | товщина поверхні | геометричні властивості сутності |
| Лінія | площа перетину лінії | геометричні властивості сутності |
| Точка | точковий обсяг | геометричні властивості сутності |

Поверхня з нульовою товщиною або лінія з нульовою поперечною площею не створює жодної жорсткості та маси - вона все ще може нести навантаження, що є саме тим, що потрібно для несучої поверхні сітчастого твердого тіла.

Матриця мас збирається лише тоді, коли це необхідно, тобто для динамічного аналізу перехідних процесів або для модального аналізу.

### 1.5 Навантаження, граничні умови та умови середовища

#### Граничні умови

| Гранична умова | Тип | Застосовується до | Компоненти |
|---|---|---|---|
| Водотоннажність | явний (Діріхле) | точка, лінія, поверхня, об'єм | Переміщення по X, Y, Z `[m]` |
| Нормальне зміщення | явний, локальний кадр | поверхні | Переміщення `[m]` |
| Роликове переміщення | явний, локальний кадр | точка, лінія, поверхня | Переміщення `[m]` |
| Сила | природний | точка, лінія, поверхня | Сила в X, Y, Z `[N]` |
| Сила (одиниця площі) | природний | поверхні | Сила на одиницю площі в X, Y, Z `[N/m^2]` |
| Тиск | природний | поверхні | Тиск `[Pa]` |
| Вага | природний | точка, лінія, поверхня | Вага `[kg]` |

**Зміщення** є умовою **необов’язкового** компонента: кожен із трьох його компонентів можна ввімкнути або вимкнути окремо. Увімкнений компонент обмежує глобальний напрямок кожного вузла сутності заданим значенням; компонент, який вимкнено, залишає цей напрямок повністю вільним. Таким чином, вимкнення *Зміщення в Y* і *Зміщення в Z* створює опору, яка утримує X і дозволяє вузлу ковзати в площині YZ.

Використовуйте замість цього *Роликове закріплення*, коли вільні напрямки не є глобальними, а дотичною площиною кривої поверхні.

**Нормальне переміщення** та **Роликове переміщення** працюють у **локальному кадрі**, створеному для кожного обмеженого вузла. За замовчуванням рамка відповідає геометрії:

- на **поверхні** локальна вісь X є усередненою нормаллю суміжних елементів поверхні;
- на **лінії** локальна рамка будується від напрямку елемента;
- у **точці** немає геометрії, щоб слідувати, тому завжди використовується напрямок, введений у граничній умові.

Відмітка **Використовувати введений локальний напрямок** замінює це для поверхні або лінії та приймає локальну вісь X від напрямку, введеного під нею. Використовуйте його, коли напрямок, який ви хочете обмежити, не є тим, який дає сітка - ролик, який має ковзати вздовж гранованої поверхні вздовж глобальної осі, наприклад.

Обмеження від різних сутностей **поєднуються** на спільному вузлі. Розв’язувач збирає кожне обмеження переміщення, що діє на вузол, кожне з них є оператором `d . u = v` щодо одного напрямку, і скорочує збір до щонайбільше трьох взаємно перпендикулярних напрямів, що утримуються Грамом-Шмідтом, переносячи задані значення за допомогою тих самих операцій. Ці утримувані напрямки стають провідними осями кадру вузла; все, що залишилося, доповнює кадр і залишається вільним. Таким чином, вузол може утримуватися в одному напрямку за допомогою глобального *Переміщення*, в іншому за допомогою *Роликове закріплення* на нахиленій грані, і залишатися вільним у третьому – ці дві умови не перезаписують одна одну, і глобально сформульований компонент ніколи не мовчки перечитується в чужому локальному кадрі.

Дві сутності, які приписують **різні значення в одному напрямку**, не можуть бути задоволені одночасно. Розв’язувач виявляє це під час ортогоналізації та зупиняється з помилкою, називаючи вузол, а не вирішує її на користь будь-якої умови, яка була прочитана останньою.

Матриці елементів і вектори навантажень вузла з обмеженнями обертаються в цей кадр, обмеження застосовується, а результуюче зміщення повертається назад. У цьому кадрі:

- **Нормальне зміщення** фіксує всі три локальні компоненти, а встановлений скаляр застосовується вздовж локальної нормалі. Вузол переміщається точно на задану величину по нормалі і фіксується в іншому випадку.
- **Зміщення ролика** фіксує лише локальний нормальний компонент на поверхні або точці, тому вузол може вільно ковзати в дотичній площині. На сутності лінії він замість цього блокує два компоненти, перпендикулярні до лінії, тому вузол може вільно ковзати вздовж лінії.

**Сила** — це загальна сила в ньютонах, розподілена на об’єкт, якому вона присвоєна. Вона ділиться на довжину об’єкта для лінії, на площу об’єкта для поверхні та на кількість точок точкового об’єкта. Тому подрібнення сітки не змінює загального навантаження.

**Сила (одиниця площі)** — це тяга в `N/m^2`, застосована в даному глобальному напрямку, інтегрована по площі елемента.

**Тиск** діє вздовж поверхні **нормально**. Розв’язувач визначає для кожної граничної поверхні, чи вказує її нормаль на сусідній елемент обчислюваного об’єму, і відповідно перевертає знак, щоб на тіло завжди тиснув позитивний тиск. Поверхня, яка не обмежує жоден об’ємний елемент, ніколи не класифікується як внутрішня, тому там навантаження діє вздовж **негативної** нормалі до поверхні – у такому випадку перевірте напрям результуючого навантаження.

**Вага** — це маса в кілограмах, прикріплена до сутності. Воно помножується на гравітаційне прискорення умов середовища та поширюється на сутність так само, як Сила. Використовуйте його для немодельованих прикріплених мас.

#### Умови середовища

| Стан середовища | Компоненти | Ефект |
|---|---|---|
| Гравітаційне прискорення | G прискорення в X, Y, Z `[m/s^2]` | власна вага і гранична умова ваги |
| Температура | Температура `[K]` | безнапруженої еталонної температури |

**Власна вага** генерується автоматично для кожної сутності, яка має як щільність, так і геометричну міру, як `rho * g`, інтегроване в елемент. Він з'являється, як тільки задана умова середовища прискорення гравітації; за замовчуванням `-9.80665 m/s^2` у Z.

**Теплове навантаження.** Різниця температур, що впливає на термін теплового розширення, становить

```
dT = element temperature - environment temperature
```

**Температура навколишнього середовища** походить від умов середовища *Температура* і є еталонним станом без напруги. **Температура елемента** надходить із розв’язувача теплопередачі, запущеного раніше в тому самому потоці завдання, і передається через спільні дані розв’язувача. Запуск *Теплопередачі*, а потім *Аналізу напруги* в одному потоці завдання дає аналіз теплового навантаження без подальшого налаштування. Без вимірювача тепла температура елемента залишається на рівні за замовчуванням, а термічний елемент є різницею лише з умовами навколишнього середовища.

#### Початкові умови

| Початковий стан | Ефект |
|---|---|
| Водотоннажність | початкове поле зміщення аналізу динамічного перехідного процесу |
| Структурна швидкість | поле початкової швидкості аналізу динамічного перехідного процесу |
| Тиск | початкове поверхневе тиск навантаження |

Початкові умови зчитуються лише під час першого запуску аналізу перехідних процесів. Динамічний аналіз без них починається зі стану спокою. Обмежені напрямки не зберігають власної початкової швидкості, вони слідують заданому переміщенню.

#### З'єднання з розчинником рідини

Розв’язувач відновлює результат **Тиск** попереднього розв’язання та використовує його як поверхневе навантаження скрізь, де не призначено чіткої граничної умови тиску. Тому завдання рідини, за яким слідує завдання напруги в тому самому потоці завдання, автоматично передає тиск рідини на конструкцію.

З іншого боку, кожен неструктурний розв’язувач переміщує сітку на збережений результат **Зміщення** перед запуском і переміщує його назад згодом, тому розв’язка рідини чи тепла, яка слідує за розв’язанням напруги, бачить деформовану форму.

### 1.6 Статичний аналіз

З вимкненим розв’язувачем часу та типом задачі, встановленим на *Аналіз стресу*, розв’язувач збирається та вирішує

```
K * u = f
```

`K` є симетричним позитивно визначеним, коли моди твердого тіла були видалені обмеженнями переміщення, тому його розв’язують за допомогою методу **кон’югованого градієнта** з попереднім зумовленням Якобі та розміром блоку 3.

Якщо модель має недостатні обмеження, матриця є сингулярною, і розв’язання не буде сходитися. Кожна статична модель потребує достатніх обмежень, щоб придушити всі шість режимів твердого тіла - три трансляції та три обертання.

### 1.7 Аналіз перехідних процесів

Якщо ввімкнено розрахунок часу, *Налаштування аналізу перехідних навантажень* вибирає один із двох типів аналізу.

#### Динамічний аналіз

За замовчуванням. Розв'язувач інтегрує рівняння лінійної еластодинаміки

```
M * d2u/dt2 + C * du/dt + K * u = f(t)
```

тому відтворюється інерція, хвилі напруги, вібрація, динамічне посилення та резонанс.

**Демпінг.** `C` — демпфування Релея, створене поелементно з двох додаткових властивостей матеріалу,

```
C = alpha_M * M + beta_K * K
```

*Масовий коефіцієнт демпфування за Релеєм* `alpha_M` `[1/s]` гасить низькі частоти, *Коефіцієнт демпфування за Релеєм* `beta_K` `[s]` високі. Коефіцієнт демпфування моди з круговою частотою `omega` становить

```
zeta(omega) = alpha_M / (2*omega) + beta_K * omega / 2
```

, тож цільове співвідношення `zeta` на двох частотах `omega_1` та `omega_2` досягається за допомогою

```
alpha_M = 2*zeta * omega_1*omega_2 / (omega_1 + omega_2)
beta_K  = 2*zeta / (omega_1 + omega_2)
```

Візьміть дві частоти з модального аналізу навколо діапазону, який вас цікавить. Типові коефіцієнти структурного демпфування становлять від 0,01 до 0,05. Без цих двох властивостей фізичного демпфування взагалі немає.

**Часове інтегрування.** Метод Ньюмарка з модифікацією Гільбера-Хьюза-Тейлора (HHT). З переміщенням `u`, швидкістю `v` і прискоренням `a` на початку кроку кожен крок вирішує

```
( a0*M + (1+alpha)*(K + a1*C) ) * u_n+1 =
      (1+alpha)*f_n+1 - alpha*f_n
    + M * ( a0*u_n + a2*v_n + a3*a_n )
    + (1+alpha) * C * ( a1*u_n + a4*v_n + a5*a_n )
    + alpha * ( C*v_n + K*u_n )
```

```
a0 = 1/(beta*dt^2)   a1 = gamma/(beta*dt)   a2 = 1/(beta*dt)
a3 = 1/(2*beta) - 1  a4 = gamma/beta - 1    a5 = dt/2 * (gamma/beta - 2)
```

, а потім оновлення

```
a_n+1 = a0*(u_n+1 - u_n) - a2*v_n - a3*a_n
v_n+1 = v_n + dt*( (1-gamma)*a_n + gamma*a_n+1 )
```

Ефективна матриця є симетричною позитивно визначеною, тому її розв’язують за допомогою того самого методу CG, що й статичний аналіз.

- З **HHT alpha = 0** (за замовчуванням) схема є простою ньюмарківською з `gamma = 1/2` і `beta = max(theta/2, 1/4)`, де `theta` є коефіцієнтом апроксимації маршу в часі (`1` назад, `0.5` по центру, `0` вперед). І центральна, і передня дають схему середнього прискорення - безумовно стабільну, точну другого порядку та вільну від чисельного демпфування. Назад дає `beta = 1/2`, який також безумовно стабільний, але подовжує періоди.
- З **HHT alpha** між `-1/3` і `0`, `gamma = 1/2 - alpha` і `beta = (1 - alpha)^2 / 4`. Схема залишається беззастережно стабільною та має точність другого порядку та гасить високі частоти, які груба сітка розрізняє погано, залишаючи низькі режими майже недоторканими. `-0.05` до `-0.1` є поширеним вибором, коли відповідь забруднена високочастотним шумом.

**Початкове прискорення.** На першому кроці прискорення розраховується з рівноваги, `M*a = f - K*u - C*v`, тому навантаження, прикладене на початку, створює правильне початкове прискорення. Напрямки без маси отримують нуль.

**Зосереджена маса.** Опція *Матриця зосередженої маси* замінює узгоджену масу на діагональну з такою ж загальною масою, масштабуючи діагональ узгодженої матриці (згрупування HRZ, яке також залишається додатним для квадратичних елементів). Це трохи знижує власну частоту і забезпечує більш плавний відгук за гострими хвильовими фронтами.

**Вибір кроку за часом.** Схема є стабільною для будь-якого `dt`, але для точності потрібно приблизно 20 кроків або більше на період найвищого режиму, який ви хочете вирішити. Для хвилі, що проходить через сітку, крок, близький до часу, необхідного хвилі для перетину одного елемента (`dt ~ h/c`, `c = sqrt(E/rho)`), є хорошим початком.

**Результати.** Окрім переміщення та напруги, динамічний аналіз зберігає вектори вузлів *Структурна швидкість* і *Структурне прискорення*. Вони також переносять стан на наступний часовий крок і перезапускають розв’язувач.

#### Квазістатичний аналіз

Кожен часовий крок є незалежним статичним рішенням

```
K * u(t) = f(t)
```

без урахування інерції та демпфування. Використовуйте його для історії навантажень, що застосовуються повільно порівняно зі структурними періодами, де має значення лише послідовність станів рівноваги. Він не потребує щільності та обмеження кроку за часом.

### 1.8 Модальний аналіз

Якщо для типу задачі встановлено значення *Модальний аналіз*, розв’язувач збирає `K` і `M` і розв’язує узагальнену задачу на власні значення

```
K * phi = lambda * M * phi        with  lambda = omega^2
```

Кожна власна пара є **режимом**: `phi` — форма режиму, що зберігається та відображається як поле зміщення, а `lambda` — власне значення, з якого випливає власна частота як

```
omega = sqrt(lambda)      [rad/s]
f     = sqrt(lambda) / (2*pi)      [Hz]
```

Розв’язувач сам виконує це перетворення: модальне налаштування та 3D-перегляд повідомляють власну частоту в Гц, тоді як журнал розв’язувача друкує базове власне значення поряд із ним. Режим, який не вдалося вирішити ітерації власного значення, повідомляється як `0` Hz із попередженням у журналі.

Доступні два методи, які вибираються налаштуванням модального методу:

| Модальний спосіб | Вирішувач власних значень | Екстракти |
|---|---|---|
| Кілька режимів | підпросторова ітерація з проекцією Релея-Рітца | необхідну кількість режимів |
| Тільки найбільш домінуючий режим | обернена степенева ітерація з коефіцієнтом Релея | єдиний режим |

Обидва методи повторюють `K^-1 * M`, тому вони зближуються до **найнижчих** частот, які є тими, що мають значення. Кожен крок є лінійним розв’язуванням із `K` із використанням налаштувань спряженого градієнта налаштування матричного вирішувача, тому вартість модального аналізу приблизно дорівнює вартості статичного розв’язання, помноженої на кількість векторів підпростору та ітерацій.

Ітерація підпростору містить блок векторів, проектує `K` і `M` на підпростір, який вони охоплюють, і точно розв’язує отриману невелику щільну задачу власних значень. Кілька додаткових векторів понад запитану кількість мод переносяться, тому що вони змушують потрібні моди сходитися помітно швидше. Для запитаних режимів `p` блок містить вектори `min(2p, p+8)`, що є звичайним компромісом між швидкістю збіжності та вартістю ітерації. Власні значення виходять безпосередньо як `lambda` і сортуються за зростанням, тому **режим 0 є основним режимом**.

**Це куди витрачається час виконання.** Одна ітерація підпростору виконує одне повне лінійне розв’язання для кожного вектора блоку, тому запит на 10 режимів коштує 18 розв’язків на ітерацію, а запит на 100 – 108. Ітерація припиняється раніше, лише коли **кожне** запитане власне значення досягає значення збіжності, а найвищий запитаний режим завжди залишається останнім. settle - тому велика кількість режимів робить кожну ітерацію дорогою та робить ранню зупинку малоймовірною. Запитайте режими, які ви насправді збираєтеся переглянути.

Якщо запитувані режими не встановилися до останньої ітерації, розв’язувач повідомляє про це в журналі та повідомляє про досягнуту зміну, замість того, щоб представляти незбіжні значення без коментарів. Найнижчі режими такого прогону зазвичай ще справні; найвищі - ні.

Матриця маси завжди збирається для модального аналізу, тому щільність має бути присутня на кожному об’єкті, який бере участь.

**Модальний аналіз попереднього напруження.** Перед складанням матриць модальний аналіз переміщує кожен вузол за результатом зміщення попереднього розв’язання, а потім відновлює сітку. Тому виконання *Аналізу напруги*, а потім *Модального аналізу* в одному потоці завдання дає режими **навантаженої, деформованої** структури, а не недеформованої. Збережена форма моди – це власний вектор, доданий поверх початкового зміщення.

Оновлюється лише геометрія - матриця жорсткості все ще є лінійно-пружною, оціненою на переміщеній сітці. Це фіксує зміну форми, а не геометричну жорсткість натягнутого елемента.

Модальний аналіз є **ексклюзивним**: його не можна поєднувати з жодною іншою фізикою, окрім попереднього аналізу напруги.

### 1.9 Похідні результати

Після розв’язання напруги елемента відновлюються з поля переміщення як середнє за точками інтегрування

```
sigma = D * ( B * u  -  eps_th )
```

з температурною деформацією `eps_th = alpha * dT * [1, 1, 1, 0, 0, 0]` для об'ємних елементів. Поверхневі елементи мають плоску деформацію: розширення за межі їх площини пригнічується, що підвищує термічну деформацію в площині до `eps_th = (1+v) * alpha * dT * [1, 1, 0]`. Така ж термічна деформація входить до теплового навантаження `f_th = INT( B^T * D * eps_th )`. Лінійні елементи звіту `E * (eps - alpha * dT)`.

З шести компонентів розв’язувач формує два інваріанти та об’єднує їх у квадратурі в напругу фон Мізеса:

```
normal part  QN = sqrt( sx^2 + sy^2 + sz^2 - (sx*sy + sy*sz + sz*sx) )
shear part   QS = sqrt( 3 * (tyz^2 + txz^2 + txy^2) )
von Mises    QVM = sqrt( QN^2 + QS^2 )
```

, що є класичним визначенням

```
QVM = sqrt( sx^2 + sy^2 + sz^2 - (sx*sy + sy*sz + sz*sx) + 3*(tyz^2 + txz^2 + txy^2) )
```

Для поверхневих елементів використовуються двовимірні еквіваленти, `QN` від двох нормальних напружень у площині та `QS = sqrt(3 * tau_xy^2)`. Для лінійних елементів повідомляється лише осьове значення, а частина зсуву дорівнює нулю.

**Вузлові сили** відновлюються елемент за елементом як внутрішня сила пружності

```
f = K * u - f_th
```

і накопичується у вузлах. У обмеженому вузлі це сила реакції; на ненавантаженому вільному вузлі він повинен бути близьким до нуля для конвергентного статичного вирішення, що робить результат Force корисною залишковою перевіркою. Таким чином, тіло, яке може вільно розширюватися, не виявляє ні сил, ні напруг.

| Результат | Звернутися до | Значення |
|---|---|---|
| Переміщення `[m]` | вузол | вектор переміщення, або форма моди в модальному аналізі |
| Наголос фон Мізеса `[Pa]` | елемент | `sqrt(QN^2 + QS^2)`, як вище |
| Нормальне напруження `[Pa]` | елемент | `QN` |
| Напруга зсуву `[Pa]` | елемент | `QS` |
| Нормальне напруження в X, Y, Z `[Pa]` | елемент | `sigma_xx`, `sigma_yy`, `sigma_zz` |
| Напруга зсуву в YZ, XZ, XY `[Pa]` | елемент | `tau_yz`, `tau_xz`, `tau_xy` |
| Сила `[N]` | вузол | відновлена ​​вузлова сила, реакція на обмежені вузли |

Шість компонентів напруги повідомляються в **глобальних** координатах для об’ємних елементів. Поверхневі та лінійні елементи оцінюють своє напруження у власній локальній рамці елементів, тому їхні компоненти повідомляються в цій рамці: поверхня заповнює `sigma_xx`, `sigma_yy` і `tau_xy` у площині, а лінія заповнює лише осьову `sigma_xx`.

### 1.10 Статичний, перехідний чи модальний?

| | Статичний | Динамічний перехідний | Квазістатичний перехідний | Модальний |
|---|---|---|---|---|
| Вирішує | `K*u = f` | `M*u'' + C*u' + K*u = f(t)` у часі | `K*u = f(t)` кожного разу | `K*phi = omega^2*M*phi` |
| Відповіді | "скільки він відхиляється і наскільки сильно він напружений" | «як він реагує на навантаження, яке швидко змінюється» | "як він відповідає навантаженню, що повільно змінюється" | "на яких частотах він хоче вібрувати та в якій формі" |
| Потребує маси | ні | так | ні | так |
| Потребує обмежень проти руху твердого тіла | так | так | так | так |
| Записи | один | один на крок часу | один на крок часу | по одному на витягнутий режим |

**Використовуйте статичний аналіз для** перевірки міцності та жорсткості, межі прогину, сил реакції, власної ваги, посудин під тиском, термічної напруги. Це значення за замовчуванням і охоплює більшість завдань.

**Використовуйте аналіз динамічних перехідних процесів** для ударів, раптових прикладених або відпущених навантажень, історії ударів і вібрації, поширення хвиль і відповіді на гармонічне збудження поблизу резонансу – усюди, де має значення інерція.

**Використовуйте квазістатичний аналіз перехідних процесів для** навантаження, яке змінюється з часом досить повільно, щоб конструкція слідувала за ним у рівновазі.

**Використовуйте модальний аналіз для** власних частот і форм мод, уникаючи резонансу з відомим збудженням, оцінюючи, чи досить жорстка конструкція динамічно, і перевіряючи наявність ненавмисних механізмів - майже нульове власне значення зазвичай означає відсутність обмеження або відключену частину.

## 2. Графічний інтерфейс користувача

Усе, що має відношення, міститься в доці **Розв’язувач** (вкладки `Problem`, `Boundary conditions`, `Initial conditions`, `Environment conditions`, `Material`, `Results`), меню **Задача** і **Модель**.

### 2.1 Вибір задачі

`Problem` -> `Problem(s) task flow` (`Ctrl+P`) відкриває діалогове вікно розв’язування задач. Додайте завдання та виберіть одне з:

- **Аналіз напруги** - "Аналіз напруги та лінійної пружно-динаміки, включаючи модальний аналіз";
- **Модальний аналіз** - «Модальний аналіз стресу».

Аналіз напруги вільно поєднується з іншими фізиками. Двома корисними ланцюжками є *Теплопередача*, потім *Аналіз напруги* для термічної напруги та *Нестислива в’язка течія*, а потім *Аналіз напруги* для навантаження тиском.

Модальний аналіз виключає будь-який інший тип задачі, за винятком попереднього стрес-аналізу, який перетворює його на попередньо напружений модальний аналіз.

### 2.2 Вкладка задачі

**Розв’язування в часі** - показано для аналізу стресу, оскільки це тип задачі, що залежить від часу. Залиште його вимкненим для статичного аналізу.

| Поле | Значення |
|---|---|
| Увімкнути | вмикає та вимикає перехідний марш |
| Наближення | встановлює бета-версію Newmark динамічного аналізу, див. 1.7; центральний є рекомендованим вибором |
| Час початку | перше значення часу в секундах; ігнорується під час перезапуску вирішувача |
| Час закінчення | `start time + time-step size * number of time-steps`, лише для читання |
| Розмір кроку в часі | `dt` за секунди |
| Кількість часових кроків | скільки кроків обчислити |
| Вихідна частота | записувати файл результатів кожні N кроків; `0` записує лише останній крок |

**Налаштування аналізу тимчасових навантажень** - показано для аналізу навантажень і активне лише тоді, коли ввімкнено розрахунок часу.

| Поле | Значення | За замовчуванням |
|---|---|---|
| Тип аналізу | *Динамічний* (з інерцією) або *Квазістатичний* (статичне розв’язання за крок у часі) | Динамічний |
| Чисельне демпфування (HHT alpha) | від `-1/3` до `0`; негативні значення вологого високочастотного шуму | 0 |
| Матриця зосереджених мас | використовувати діагональну матрицю мас замість узгодженої | вимкнено |

Останні два застосовуються лише до динамічного аналізу та неактивні в інших випадках.

**Налаштування модального аналізу** - відображається, якщо тип задачі *Модальний аналіз*.

| Поле | Значення | За замовчуванням |
|---|---|---|
| Модальний спосіб | *Лише найбільш домінуючий режим* або *Кілька режимів* | Кілька режимів |
| Ітерації | ітерації вирішувача власних значень; вимкнено для методу домінуючого режиму | 100 |
| Режими вилучення | скільки режимів видобувати; вимкнено для методу домінуючого режиму | 10 |
| Значення збіжності | поріг збіжності вирішувача власних значень | 1.0e-9 |

Два підрахунки є незалежними: ітерації вдосконалюють весь набір режимів разом, вони не створюють їх по одному.

**Витягти режими — це параметр, який визначає, скільки часу триватиме цикл.** Кожен режим додає лінійне розв’язання до кожної ітерації, і цикл можна зупинити достроково лише після встановлення всіх запитаних режимів, тому вартість зростає швидше, ніж кількість. Десять є розумною початковою точкою і є типовою; сотня – це інший порядок обчислення, і на великій сітці це може зайняти години. Підвищуйте його лише тоді, коли знаєте, що вам потрібні вищі режими.

Якщо виконання займає більше часу, ніж ви очікуєте, журнал розв’язувача називає вектор підпростору, над яким він працює, тому прогрес у межах ітерації стає видимим, і він друкує швидкість збіжності, досягнуту після кожної ітерації, поруч із потрібним значенням.

### 2.3 Вкладка Матеріал

Вкладка `Material` містить список матеріалів, призначених вибраній сутності. Аналіз напруги вимагає **всіх чотирьох** з них:

| Власність | Одиниці | Коментар |
|---|---|---|
| Модуль пружності | `Pa` | `E`, про `2.1e11` для сталі |
| Коефіцієнт Пуассона | `-` | `v`, близько `0.3` для сталі; повинен залишатися нижче `0.5` |
| Щільність | `kg/m^3` | необхідний для власної ваги, динамічного та модального аналізу |
| Коефіцієнт теплового розширення | `1/K` | встановити `0`, якщо немає теплового навантаження |

Сутність, у якій відсутній будь-який із них, не вирішується, і засіб перевірки налаштувань попереджає перед початком запуску.

Ще дві властивості є необов’язковими та зчитуються лише за допомогою динамічного аналізу перехідних процесів:

| Власність | Одиниці | Коментар |
|---|---|---|
| Масовий коефіцієнт демпфування Релея | `1/s` | `alpha_M`, див. 1.7; нуль при відсутності |
| Коефіцієнт демпфування жорсткості за Релеєм | `s` | `beta_K`, див. 1.7; нуль при відсутності | Кожна властивість є таблицею температур, тому a
залежний від температури модуль враховується, коли спочатку запускається тепловимірювач.

### 2.4 Вкладка Граничні умови

Вкладка розділена на список менеджера доступних граничних умов угорі та редактор для вибраного нижче. Спочатку виберіть сутність у дереві `Model`; потім менеджер пропонує умови, дійсні для цього типу сутності та для вибраної задачі. Позначте один, щоб призначити його, а потім відредагуйте його компоненти в нижньому дереві.

Пропонуються умови розділу 1.5. Примітки щодо їх використання:

- **Зміщення** показує прапорець біля кожного з трьох компонентів. Лише позначені компоненти обмежені, тому грань можна утримувати в X і залишати вільною в Y і Z. Поле значення непозначеного компонента неактивне.
- **Нормальне переміщення** і **Роликове переміщення** за замовчуванням беруть свій локальний каркас із геометрії - усереднені нормалі елемента поверхні, напрямок елемента лінії. У **точковій** сутності немає геометрії, якій слід слідувати, тому редактор *Локального напрямку* завжди відображається та завжди використовується.
- На поверхні або лінії дерево умов показує прапорець **Використовувати введений місцевий напрямок**. Поставте прапорець, щоб відкрити редактор *Локальний напрямок* і взяти кадр з указаного вами напрямку, а не з сітки. Стрілки напрямку, намальовані в 3D-перегляді, слідують за будь-якою з двох діючих. Якщо обмеження поверхні поводиться дивно, якщо прапорець не встановлено, перевірте узгодженість нормалей поверхні та синхронізуйте їх із інструментами геометрії.
- Обмеження від кількох сутностей, що зустрічаються в одному вузлі, об’єднуються, тому грань може одночасно утримуватись у глобальному напрямку за допомогою *Зміщення* та котитися по нахиленій площині. Якщо два з них запитують різні значення в одному напрямку, виконання зупиняється з помилкою, яка називає вузол.
- **Тиск** і **Сила (одиниця площі)** застосовуються лише до поверхонь.
- Кожен компонент є таблицею часу, тому навантаженню можна надати часову історію для тимчасового запуску.

### 2.5 Початкові умови та умови середовища

На вкладці `Environment conditions` увімкнено **гравітацію**. Призначте *гравітаційне прискорення* об’єкту, який повинен нести власну вагу – як правило, усій моделі – та встановіть вектор; за замовчуванням `-9.80665` у Z. Призначте *Температура*, щоб встановити контрольну температуру без напруги для аналізу термічної напруги.

Вкладка `Initial conditions` пропонує *Переміщення*, *Структурну швидкість* і *Тиск*, застосовані під час першого запуску аналізу перехідних процесів.

### 2.6 Налаштування вирішувача матриць

`Problem` -> `Setup Problem(s) matrix solver` налаштовує ітераційні вирішувачі. Структурний розв’язувач використовує запис **CG** як для статичного та перехідного розв’язування, так і для внутрішнього розв’язання ітерації власного значення.

Якщо статичне розв’язування не збігається, звичайною причиною є недостатньо обмежена модель, а не налаштування вирішувача. Перевірте обмеження перед збільшенням кількості ітерацій.

### 2.7 Точки моніторингу

`Problem` -> `Define monitoring points` розміщує зонди в заданих координатах і вибирає змінну для запису - як правило, *Переміщення* або *Напруга Фон Мізеса*. У перехідному циклі історія відображається `Report` -> `Monitoring points`.

### 2.8 Результати та записи

Вкладка `Results` містить список обчислених змінних і керує 3D-переглядом. Переміщення — вузловий вектор; три міри напруги є скалярами елементів. Динамічний аналіз перехідних процесів додає вектори вузлів *Структурна швидкість* і *Структурне прискорення*.

Для графіка деформованої форми відобразіть *Переміщення* і ввімкніть масштабування деформації в налаштуваннях перегляду - реальні зміщення зазвичай надто малі, щоб побачити їх у справжньому масштабі.

Вкладка `Records` дока `Model` містить список записів результатів:

- **статичний аналіз** - один запис;
- **перехідний аналіз** - один запис на записаний часовий крок;
- **модальний аналіз** - один запис на витягнутий режим, пронумерований від основного. Переглядаючи записи, ви переходите між режимами, а їх анімація оживляє форми режимів.

Для модального запису 3D-перегляд позначає запис номером режиму та власною частотою цього режиму в Гц.

`Report` -> `Solver log file` показує повний вихід розв’язувача, включаючи власне значення, надруковане для кожної виділеної моди, і статистику переміщення, напруги фон Мізеса та сили після кожного запису.

## 3. Підручник - аналіз статичних напруг

**Ціль.** Обчисліть прогин і напругу консолі, навантаженої власною вагою та навантаженням на вершину, і прочитайте реакцію на опорі.

У цьому підручнику передбачається модель сітчастого об’єму – довгий ящик працює добре. Використовуйте `File` -> `New model`, намалюйте прямокутник за допомогою `Geometry` -> `Create element` або імпортуйте геометрію та тетраедралізуйте її; підручник *Побудова куба* охоплює цю тему. Позначте фіксований кінець і навантажений кінець як окремі сутності поверхні, щоб їм можна було призначити граничні умови.

### Крок 1 - виберіть задачу

1. `Problem` -> `Problem(s) task flow` (`Ctrl+P`).
2. Додайте завдання та виберіть **Аналіз напруги**.
3. Підтвердьте за допомогою `OK`.

### Крок 2 - призначити матеріал

1. Виберіть сутність обсягу в дереві `Model`.
2. Відкрийте вкладку `Material` і призначте матеріал з усіма чотирма властивостями для конструкційної сталі:
   - **Модуль пружності** = `2.1e11` `Pa`
   - **Коефіцієнт Пуассона** = `0.3`
   - **Щільність** = `7850` `kg/m^3`
   - **Коефіцієнт теплового розширення** = `1.2e-5` `1/K`

### Крок 3 - збережіть аналіз статичним

Відкрийте вкладку `Problem` і залиште **Увімкнути** непозначеним у груповому полі *Розв’язування в часі*. Потім розв’язувач збирає та розв’язує `K*u = f` один раз.

### Крок 4 - обмежте модель

1. Виберіть поверхню на фіксованому кінці.
2. Відкрийте вкладку `Boundary conditions` і відзначте **Переміщення**.
3. Залиште всі три компоненти позначеними та встановіть значення `0`.

Це повністю фіксує обличчя та усуває всі шість режимів жорсткого тіла. Переконайтеся, що нічого іншого не залишилося плаваючим - відключена частина без обмежень робить систему сингулярною, і розв'язання не сходиться.

Для опори, яка має ковзати, а не бути повністю зафіксованою, замість цього використовуйте **Роликове переміщення** на поверхні. Він фіксує лише напрям нормалі поверхні та залишає вузол вільним для переміщення в дотичній площині.

### Крок 5 - прикладіть навантаження

**Власна вага.** Виберіть сутність об’єму, відкрийте вкладку `Environment conditions` і відзначте **Прискорення тяжіння**. Залиште `-9.80665` за замовчуванням у Z.

**Навантаження наконечника.** Виберіть об’єкт поверхні на вільному кінці, відкрийте вкладку `Boundary conditions` і встановіть прапорець **Сила**. Введіть загальну силу в ньютонах, наприклад `-1000` у Z. Значення є загальною силою над об’єктом, тому воно не змінюється під час уточнення сітки.

Альтернативи, залежно від фізичного навантаження:

- **Тиск** для рівномірного нормального тиску на обличчя, в `Pa`;
- **Сила (одиниця площі)** для спрямованої тяги в `N/m^2`;
- **Вага** для приєднаної маси в `kg`, яка не моделюється як геометрія.

### Крок 6 - розв'язати

1. `Solution` -> `Start solver` (`Ctrl+R`).
2. Засіб перевірки налаштувань повідомляє про відсутність матеріалів або граничних умов перед початком циклу.
3. Слідкуйте за прогресом у `Report` -> `Solver log file`.

### Крок 7 - перевірте результати

- Вкладка `Results`: відображення **Зміщення**, щоб побачити деформовану форму, і **Напруга Фон Мізеса** для розподілу напруги. Увімкніть масштабування деформації в налаштуваннях перегляду, щоб зробити прогин видимим.
- **Нормальна напруга** і **Напруга зсуву** відокремлюють два внески, які складають зареєстроване значення фон Мізеса.
- **Сила** на нерухоме обличчя є реакцією. Його сума повинна врівноважувати прикладене навантаження плюс власну вагу - це швидка та ефективна перевірка того, що модель завантажена так, як ви планували.
- точка моніторингу на *Зміщенні* на кінчику дає відхилення числом, а не кольором.

### Крок 8 - необов'язковий, термічний стрес

Щоб додати теплове навантаження:

1. Додайте завдання **Теплопередача** *перед* завданням напруги в потоці завдання задачі та встановіть його граничні умови та властивості матеріалу.
2. Призначте умову навколишнього середовища **Температура** для структурного елемента з еталонною температурою без напруги, наприклад `293.15` K.

Розрахунок напруги збирає обчислені температури елементів із розраховувача тепла та автоматично додає термін теплового розширення.

### Усунення несправностей

| Симптом | Причина |
|---|---|
| Розв'язати не сходиться | модель недостатньо обмежена; деталь плаває або опори не знімають усі шість режимів твердого тіла |
| *Об’єкту призначено матеріал, якому відсутні необхідні властивості* | одна з чотирьох необхідних властивостей відсутня |
| Переміщення всюди дорівнюють нулю | жодне навантаження не досягло моделі - перевірте, чи призначено силу тяжіння, чи компоненти сили відмінні від нуля |
| Переміщення величезні | модуль пружності неправильний на порядки, або поверхня має нульову товщину і, отже, не має жорсткості |
| Навантаження змінюється, коли сітка уточнюється | a *Сила (одиниця площі)* або *Тиск* мали на увазі загальну силу або навпаки |
| Тиск штовхає не в ту сторону | нормалі поверхні неузгоджені, або поверхня не обмежує об’єм |

## 4. Підручник - модальний аналіз

**Ціль.** Витягніть кілька перших природних режимів того самого кантилевера.

### Крок 1 - виберіть задачу

`Problem` -> `Problem(s) task flow` (`Ctrl+P`), додайте завдання, виберіть **Модальний аналіз**.

Модальний аналіз не можна поєднувати з іншою фізикою, за винятком аналізу напруги, розміщеного перед ним, що робить його попередньо напруженим модальним аналізом.

### Крок 2 - призначити матеріал

Ті самі чотири властивості, що й у статичному посібнику. **Щільність** тут має більше значення, ніж деінде: це вся матриця мас, а частоти масштабуються як `1/sqrt(rho)`.

### Крок 3 - обмежте модель

Призначте ту саму граничну умову **Зміщення** на фіксованому кінці.

Обмеження - це те, що відрізняє режими кантилевера від режимів вільного плаваючого стрижня. Якщо модель залишити без обмежень, перші шість власних значень будуть близькими до нуля - моди твердого тіла - і цікаві моди будуть висунуті далі в списку.

### Крок 4 - налаштуйте модальне налаштування

Відкрийте вкладку `Problem` і в *Налаштування модального аналізу* встановіть:

| Поле | Значення |
|---|---|
| Модальний спосіб | `Multiple modes` |
| Ітерації | `100` |
| Режими вилучення | `6` |
| Значення збіжності | `1.0e-9` |

Шість режимів є розумною відправною точкою, але менше, ніж десять стандартних режимів. Кожний додатковий режим додає лінійне рішення до кожної ітерації, тому підрахунок великого режиму на великій сітці є повільним.

Виберіть `Only most dominant mode`, коли потрібен лише один режим; він використовує зворотну ітерацію ступеня на одному векторі та набагато дешевший.

### Крок 5 - навантаження не потрібні

Модальний аналіз не має вектора навантаження – задача власних значень є однорідною. Навантаження, призначені для моделі, ігноруються, за одним винятком: якщо раніше проводився аналіз напруги, результат його зміщення деформує сітку для модальної збірки.

### Крок 6 - розв'язати

`Solution` -> `Start solver` (`Ctrl+R`). Журнал повідомляє про ітерації підпростору та їхню швидкість збіжності, а потім один блок на витягнутий режим:

```
Extracting mode 6
{
    Eigen-value = ...
    Storing results
    ...
}
```

Режими обробляються від найвищого вилученого індексу до фундаментального, тому фундаментальний є останнім обчисленим і зберігається як запис 1.

### Крок 7 - перевірте режими

- Док `Model`, вкладка `Records`: один запис на режим, пронумерований від основного. Перегляньте їх, щоб побачити форму кожного режиму.
- вкладка `Results`: відображення **Переміщення**. Форма режиму визначається лише з точністю до масштабного коефіцієнта, тому величини є довільними – важлива форма. Увімкніть масштабування деформації та анімуйте запис, щоб візуалізувати режим.
- Власне значення кожного режиму друкується в журналі розв'язувача та відображається як мітка запису в 3D-виді.

### Крок 8 - читання власних частот

Тривимірне подання позначає кожен модальний запис його номером режиму та його власною частотою в Гц. Журнал розв’язувача містить однакову частоту для кожної вилученої моди разом із основним власним значенням:

```
Eigen-value = 1e+06, frequency = 159.155 [Hz]
```

Режим, який ітерація власного значення не може вирішити, повідомляється як `0` Hz і містить попередження в журналі.

Як і з будь-яким іншим результатом, варто перевірити основну частоту за ручним розрахунком під час першого налаштування моделі - розділ 5 надає формулу для кантилевера.

### Крок 9 - необов'язкові, попередньо напружені режими

1. У потоці розв’язування задач розмістіть завдання **Аналіз напруги** *перед* завданням **Модальний аналіз**.
2. Встановіть статичні навантаження та обмеження, як у посібнику 3.

Потім модальний аналіз виконується на деформованій сітці. Це спосіб побачити, як статичне навантаження змінює форму вібрації конструкції.

## 5. Перевірка моделі

Розв’язувач не має вбудованого набору перевірок, тому варто перевірити нову модель на те, що ви можете обчислити вручну, перш ніж довіряти їй. Три дешеві чеки в порядку корисності:

**Баланс реакції.** Підсумуйте результат *Сили* для обмежених вузлів. Він повинен збалансувати прикладені навантаження плюс власну вагу `rho * V * g`. Це вловлює неправильні величини навантаження, неправильні одиниці вимірювання та неправильні напрямки тиску.

**Відхилення верхівки консолі.** Для балки довжиною `L`, другим моментом площі `I` і кінцевим навантаженням `F` теорія Ейлера-Бернуллі дає

```
delta = F * L^3 / (3 * E * I)
```

Змоделюйте промінь елементами об’єму та порівняйте. Очікуйте, що результат скінченних елементів буде трохи жорсткішим на грубій сітці, зближуючись знизу в міру уточнення сітки. Не використовуйте для цієї перевірки рядкові елементи - вони не мають жорсткості на вигин.

**Консольна основна частота.** Для того самого променя з площею поперечного перерізу `A`,

```
f1 = (1.875^2 / (2*pi)) * sqrt( E*I / (rho * A * L^4) )
```

Порівняйте з `sqrt(lambda_0) / (2*pi)` з модального аналізу. Це одночасно перевіряє матрицю маси, матрицю жорсткості та перетворення власних значень.

**Раптово навантажений стрижень.** Стержень, закріплений на одному кінці та навантажений на іншому осьовою силою `F`, увімкненою на `t = 0`, є перевіркою динамічного аналізу. Хвиля напруги біжить до нерухомого кінця і назад зі швидкістю `c = sqrt(E/rho)`, тому вільний кінець рухається лінійно до подвійного статичного відхилення, `2 * F * L / (E * A)`, при `t = 2*L/c` і назад до нуля при `t = 4*L/c`. Без демпфування цикл повторюється. З демпфуванням Релея він згасає, і стрижень зупиняється на статичній деформації. Використовуйте нульовий коефіцієнт Пуассона, щоб стовпчик був дійсно одновимірним.

Для будь-якого з них уточніть сітку принаймні один раз і підтвердьте, що відповідь збігається, а не дрейфує.

## 6. Обмеження

### Обмеження моделювання

- **Лише лінійна пружність.** Невеликі деформації, малі переміщення, ізотропний матеріал, відсутність пластичності, відсутність контакту, відсутність великої деформації та вигину. Результати мають значення лише тоді, коли структура залишається в своєму лінійному діапазоні.
- **Демпінг – це лише демпфування Релея.** Матриця демпфування становить `alpha_M*M + beta_K*K` для кожного матеріалу, тому коефіцієнт демпфування відповідає кривій 1,7 і не може бути встановлений режим за режимом. Немає дискретних демпферів, незалежного від частоти (гістерезисного) демпфування та граничних умов демпфування.
- **Лише неявне інтегрування часу.** Кожен крок є лінійним рішенням. Немає чіткої схеми центральних відмінностей, тому дуже короткі події, такі як балістичний удар, потребують багатьох дорогих етапів.
- **Елементи поверхні є плоскою деформацією.** Тонка пластина, навантажена у власній площині, буде жорсткішою, ніж ідеалізація плоского напруження. Моделюйте тонкі конструкції з об’ємними елементами, коли різниця має значення.
- **Лінійні елементи є фермами.** Збирається тільки осьова жорсткість `E*A`. Немає вигину, зсуву чи кручення, незалежно від типу елемента, тому каркас, змодельований лінійними елементами, поводитиметься як ферма, з’єднана штифтами.
- **Попереднє напруження лише геометричне.** Модальний аналіз попереднього напруження повторно оцінює лінійну жорсткість переміщеної сітки. Це не додає члена геометричної жорсткості, тому посилення натягнутого троса або пом’якшення стиснутої стійки не враховується.
- **Без модальних факторів участі або ефективних мас.** Розв’язувач повідомляє лише про власні значення та форми мод, тому немає прямої вказівки на те, які моди важливі для даного напрямку збудження.

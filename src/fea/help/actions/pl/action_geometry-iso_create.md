# Utwórz izopowierzchnię

**Encja ISO** to rodzaj encji interpolowanej, podobnej do **przekroju**. **Encja ISO** to „powierzchnia warstwicowa” wyznaczona na podstawie wartości skalarnej lub modułu wektora.


**Encję ISO** można utworzyć na dowolnej encji objętości lub powierzchni z dowolnej zmiennej wynikowej, którą można zastosować w węzłach. **Zmienne wynikowe**, które domyślnie dotyczą elementów, takie jak **Von Mises Stress** (naprężenie zredukowane według von Misesa), należy najpierw przekształcić na zmienne węzłowe.

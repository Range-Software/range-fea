# Przebieg zadań problemów

Konfiguruje **przebieg zadań problemu**.


**Zadanie problemu** reprezentuje konkretny problem fizyczny, taki jak **Stress analysis** (analiza naprężeń), **Electro-statics** (elektrostatyka) itp.


**Przebieg zadań problemu** to lista lub drzewo różnych **zadań problemu**, określające kolejność i liczbę wykonań każdego **zadania problemu**. W tym miejscu można ustawić liczbę iteracji problemów nieliniowych.

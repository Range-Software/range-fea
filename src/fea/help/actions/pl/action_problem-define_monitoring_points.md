# Zdefiniuj punkty monitorowania

**Punkty monitorowania** są definiowane przez współrzędne X, Y i Z i można do nich przypisać dowolną **zmienną** danego **typu problemu**. Na przykład w **przejściowej wymianie ciepła** można przypisać zmienną **Temperature** (temperatura) do **punktu monitorowania**, aby śledzić jej przebieg w danym punkcie przestrzeni.

# Utwórz pole wektorowe

**Pole wektorowe**:

- Pomaga wizualizować pola, takie jak prędkość, pole elektryczne i magnetyczne, przepływ ciepła i siły.
- Można je utworzyć na dowolnej encji modelu lub na powierzchni interpolowanej, takiej jak **przekroje** i **izopowierzchnie**.

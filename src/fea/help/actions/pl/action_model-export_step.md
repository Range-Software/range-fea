# Eksportuj model STEP

Eksportuje wybrany model do pliku typu **STEP** (ISO 10303-21, AP214).

Każda powierzchnia modelu jest zapisywana jako osobna bryła złożona z płaskich ścian trójkątnych. Powierzchnie zamknięte są zapisywane jako bryły, otwarte jako powłoki. Współrzędne są zapisywane w metrach.

# Pliki tymczasowe

Otwiera folder z plikami tymczasowymi utworzonymi przez aplikację. Folder zostaje otwarty w przeglądarce plików systemu operacyjnego (Finder w macOS, Eksplorator plików w Windows, menedżer plików w Linuksie).

Foldery aplikacji znajdują się w `Documents/Range Software/FEA` w folderze domowym użytkownika. Wersja z Mac App Store przechowuje je w `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA`, ponieważ piaskownica nie pozwala jej zapisywać w folderze Dokumenty.

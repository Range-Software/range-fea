# Exportovať STEP model

Exportuje vybraný model do súboru typu **STEP** (ISO 10303-21, AP214).

Každý povrch modelu je zapísaný ako samostatné teleso zložené z rovinných trojuholníkových plôch. Uzavreté povrchy sú uložené ako objemové telesá, otvorené povrchy ako škrupiny. Súradnice sú zapísané v metroch.

# Documents

Open the folder with generated documents and reports. The folder is opened in the file browser of the operating system (Finder on macOS, File Explorer on Windows, the file manager on Linux).

Application folders are located in `Documents/Range Software/FEA` in the user's home folder. The Mac App Store version keeps them in `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA`, as the sandbox does not allow it to write to the Documents folder.

# Визначення точок моніторингу

**Точки моніторингу** визначаються координатами X Y і Z і їм можна призначити будь-яку **Змінну** для заданого **Типу задачі**. Наприклад, у **Перехідному теплообміну** змінну **Температуру** можна призначити **точці моніторингу**, щоб побачити прогрес у певній точці простору.

# Матеріали

Відкриває теку з базою даних матеріалів. Тека відкривається у файловому менеджері операційної системи (Finder у macOS, Провідник у Windows, файловий менеджер у Linux).

Теки програми розташовані в `Documents/Range Software/FEA` у домашній теці користувача. Версія з Mac App Store зберігає їх у `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA`, оскільки пісочниця не дозволяє їй записувати в теку Документи.

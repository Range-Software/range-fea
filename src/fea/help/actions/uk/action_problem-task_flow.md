# Задачі

Налаштуйте **Послідовність розв’язування задач**.


**Проблемне завдання** представляє реальну фізичну задачу, наприклад **Аналіз напруги**, **Електростатика** тощо.


**Послідовність розв’язування задач** — це список або дерево різних **розв’язування задач** і визначає порядок і кількість виконання кожного **розв’язування задач**. Це місце, де можна встановити кількість ітерацій для нелінійних задач.

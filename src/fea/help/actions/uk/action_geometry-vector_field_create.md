# Створення векторного поля

**Векторне поле**:

- Допомагає візуалізувати такі поля, як швидкість, електричні та магнітні поля, тепловий потік і сили.
- можна створити на будь-якій сутності моделі або інтерпольованій поверхні, наприклад **Порізи** та **поверхні ISO**.

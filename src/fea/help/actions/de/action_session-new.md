# Neue Sitzung

Erstellt eine neue **Sitzung**.


Eine **Sitzung** dient als „Container“ für mehrere Modelle. Diese Modelle sind nicht direkt miteinander verknüpft, daher können zwischen ihnen keine Daten ausgetauscht oder geteilt werden. Zweck der Sitzung ist es, an mehreren Modellen gleichzeitig arbeiten zu können.

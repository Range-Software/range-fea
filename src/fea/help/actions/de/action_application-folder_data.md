# Daten

Öffnet den Datenordner mit Modellen und Dateien, die mit **Range Cloud** ausgetauscht werden. Der Ordner wird im Dateibrowser des Betriebssystems geöffnet (Finder unter macOS, Datei-Explorer unter Windows, Dateimanager unter Linux).

Die Ordner der Anwendung befinden sich in `Documents/Range Software/FEA` im Benutzerordner. Die Version aus dem Mac App Store legt sie in `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA` ab, da die Sandbox das Schreiben in den Ordner Dokumente nicht erlaubt.

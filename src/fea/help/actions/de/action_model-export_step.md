# STEP-Modell exportieren

Exportiert das ausgewählte Modell in eine Datei vom Typ **STEP** (ISO 10303-21, AP214).

Jede Oberfläche des Modells wird als eigener Körper aus ebenen Dreiecksflächen geschrieben. Geschlossene Oberflächen werden als Volumenkörper, offene Oberflächen als Schalen gespeichert. Koordinaten werden in Metern geschrieben.

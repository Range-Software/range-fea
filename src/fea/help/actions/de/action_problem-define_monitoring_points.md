# Überwachungspunkte definieren

**Überwachungspunkte** werden durch X-, Y- und Z-Koordinaten definiert, und ihnen kann jede **Variable** des jeweiligen **Problemtyps** zugewiesen werden. Beispielsweise kann bei der **transienten Wärmeübertragung** die Variable **Temperatur** einem **Überwachungspunkt** zugewiesen werden, um ihren Verlauf an diesem Punkt im Raum zu verfolgen.

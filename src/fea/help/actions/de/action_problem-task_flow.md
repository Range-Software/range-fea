# Aufgabenablauf der Probleme

Konfiguriert den **Aufgabenablauf des Problems**.


Eine **Problemaufgabe** stellt ein konkretes physikalisches Problem dar, wie **Spannungsanalyse**, **Elektrostatik** usw.


Der **Aufgabenablauf des Problems** ist eine Liste oder ein Baum verschiedener **Problemaufgaben** und legt die Reihenfolge und Anzahl der Ausführungen jeder **Problemaufgabe** fest. Hier kann die Anzahl der Iterationen für nichtlineare Probleme eingestellt werden.

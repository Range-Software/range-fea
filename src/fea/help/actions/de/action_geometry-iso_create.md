# ISO erstellen

Die **ISO-Entität** ist eine Form einer interpolierten Entität, ähnlich dem **Schnitt**. Die **ISO-Entität** ist eine „Schichtfläche“ auf Basis eines Skalarwerts oder des Betrags eines Vektors.


Eine **ISO-Entität** kann auf jeder Volumen- oder Flächenentität aus jeder Ergebnisvariable erstellt werden, die auf Knoten anwendbar ist. **Ergebnisvariablen**, die standardmäßig auf Elementen anwendbar sind, wie **Vergleichsspannung nach von Mises**, müssen zuerst in Knotenvariablen umgewandelt werden.

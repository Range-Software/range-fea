# Crea ISO

L'**entità ISO** è una forma di entità interpolata simile alla **sezione**. L'**entità ISO** è una «superficie di livello» basata su un valore scalare o sul modulo di un vettore.


Un'**entità ISO** può essere creata su qualsiasi entità volume o superficie a partire da qualsiasi variabile di risultato applicabile ai nodi. Le **variabili di risultato** applicabili per impostazione predefinita agli elementi, come la **tensione di von Mises**, devono prima essere convertite in variabili nodali.

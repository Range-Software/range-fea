# Dati

Apre la cartella dati con i modelli e i file scambiati con **Range Cloud**. La cartella viene aperta nel gestore file del sistema operativo (Finder su macOS, Esplora file su Windows, il file manager su Linux).

Le cartelle dell'applicazione si trovano in `Documents/Range Software/FEA` nella cartella home dell'utente. La versione del Mac App Store le conserva in `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA`, poiché la sandbox non le consente di scrivere nella cartella Documenti.

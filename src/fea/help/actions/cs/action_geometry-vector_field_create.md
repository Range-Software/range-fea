# Vytvořit vektorové pole

**Vektorové pole**:

- Pomáhá zobrazit pole, jako je rychlost, elektrické a magnetické pole, tok tepla a síly.
- Lze ho vytvořit na libovolné entitě modelu nebo na interpolovaném povrchu, jako jsou **řezy** a **ISO plochy**.

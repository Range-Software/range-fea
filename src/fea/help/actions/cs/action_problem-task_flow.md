# Pořadí kroků úloh

Nastavení **pořadí kroků úlohy**.


**Krok úlohy** představuje konkrétní fyzikální úlohu, například **analýzu napětí**, **elektrostatiku** apod.


**Pořadí kroků úlohy** je seznam nebo strom různých **kroků úlohy**, který určuje pořadí a počet provedení každého **kroku úlohy**. Zde lze nastavit počet iterací pro nelineární úlohy.

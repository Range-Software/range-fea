# Exportovat model STEP

Exportuje vybraný model do souboru typu **STEP** (ISO 10303-21, AP214).

Každý povrch modelu je zapsán jako samostatné těleso složené z rovinných trojúhelníkových ploch. Uzavřené povrchy jsou uloženy jako objemová tělesa, otevřené povrchy jako skořepiny. Souřadnice jsou zapsány v metrech.

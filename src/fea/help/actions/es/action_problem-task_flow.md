# Flujo de tareas de los problemas

Configura el **flujo de tareas del problema**.


Una **tarea de problema** representa un problema físico concreto, como **Stress analysis** (análisis de tensiones), **Electro-statics** (electrostática), etc.


El **flujo de tareas del problema** es una lista o un árbol de distintas **tareas de problema** que define el orden y el número de ejecuciones de cada **tarea de problema**. Aquí es donde se puede fijar el número de iteraciones de los problemas no lineales.

# Definir puntos de monitorización

Los **puntos de monitorización** se definen mediante coordenadas X, Y y Z, y se les puede asignar cualquier **variable** del **tipo de problema** dado. Por ejemplo, en una **transferencia de calor transitoria** se puede asignar la variable **Temperature** (temperatura) a un **punto de monitorización** para seguir su evolución en un punto dado del espacio.

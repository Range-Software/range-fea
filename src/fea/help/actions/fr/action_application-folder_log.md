# Journaux

Ouvre le dossier contenant les fichiers journaux de l'application. Le dossier est ouvert dans le navigateur de fichiers du système d'exploitation (Finder sous macOS, Explorateur de fichiers sous Windows, gestionnaire de fichiers sous Linux).

Les dossiers de l'application se trouvent dans `Documents/Range Software/FEA` du dossier personnel de l'utilisateur. La version du Mac App Store les place dans `~/Library/Containers/com.range-software.fea/Data/Library/Application Support/Range Software/FEA`, car le bac à sable ne lui permet pas d'écrire dans le dossier Documents.

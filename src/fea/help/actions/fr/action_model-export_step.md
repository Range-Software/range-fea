# Exporter le modèle STEP

Exporte le modèle sélectionné dans un fichier de type **STEP** (ISO 10303-21, AP214).

Chaque surface du modèle est écrite comme un corps distinct composé de faces triangulaires planes. Les surfaces fermées sont enregistrées comme solides, les surfaces ouvertes comme coques. Les coordonnées sont écrites en mètres.

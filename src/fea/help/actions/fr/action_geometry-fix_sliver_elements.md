# Corriger les éléments dégénérés

Recherche les éléments dégénérés et les corrige automatiquement.

Un élément est considéré comme dégénéré en fonction du rapport entre son arête la plus longue et son arête la plus courte.

```
  |\
  | \
  |  \ c
a |   \
  |    \
  |_____\
     b
  où : rapport des arêtes = c / b
```

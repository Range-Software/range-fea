# Créer une ISO

L'**entité ISO** est une forme d'entité interpolée semblable à la **coupe**. L'**entité ISO** est une « surface de niveau » fondée sur une valeur scalaire ou sur la norme d'un vecteur.


Une **entité ISO** peut être créée sur n'importe quelle entité volume ou surface à partir de toute variable de résultat applicable aux nœuds. Les **variables de résultat** applicables par défaut aux éléments, comme la **contrainte de von Mises**, doivent d'abord être converties en variables nodales.

# Créer un champ vectoriel

**Champ vectoriel** :

- Aide à visualiser des champs tels que la vitesse, les champs électrique et magnétique, le flux thermique et les forces.
- Peut être créé sur toute entité du modèle ou surface interpolée comme les **coupes** et les **surfaces ISO**.

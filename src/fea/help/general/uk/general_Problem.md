# Задача

**Задача** — це загальний термін для одного або кількох фізичних явищ, застосованих до геометрії. Вона визначається **типом задачі**, **специфічними налаштуваннями задачі**, **граничними умовами**, **початковими умовами**, **умовами навколишнього середовища** та **налаштуваннями матеріалу**.

Задача визначається окремо для кожної моделі. Її частини налаштовуються на вкладках у правій частині головного вікна: **Задача**, **Граничні умови**, **Початкові умови**, **Умови навколишнього середовища** та **Матеріал**.

## Вибір задачі

**Меню:** _Задача -> Вибрати задачу_

Діалогове вікно **Вибрати задачу** використовується для вибору того, що потрібно розв’язати (див. [Тип задачі](general_Problem_type.md)). Воно також з’являється автоматично після завантаження моделі без жодної задачі. Доки задачу не вибрано, вкладка **Задача** містить лише кнопку **Вибрати задачу**.

## Специфічні налаштування задачі

Після вибору задачі вкладка **Задача** містить налаштування, специфічні для вибраних **типів задач**.

![Вкладка Задача](image-Problem_tab.png)

- **Розв’язування в часі** – позначте, щоб розв’язувати задачу як **нестаціонарну** (залежну від часу). Після цього можна задати метод апроксимації, початковий час, розмір кроку за часом, кількість кроків за часом і частоту виведення; кінцевий час обчислюється з них (_кінцевий час = початковий час + розмір кроку за часом * кількість кроків за часом_). Якщо прапорець не позначено, задача розв’язується як **стаціонарна**. Розв’язування в часі доступне лише для типів задач, які його підтримують.
- Інші розділи залежать від вибраних **типів задач** (наприклад, **Налаштування нестаціонарного аналізу напружень**, налаштування випромінювання, акустики або модального аналізу).

Інші дії, пов’язані із задачею, знаходяться в меню **Задача**: _Налаштувати розв’язувач систем рівнянь_, _Визначте точки моніторингу_ та _Скинути налаштування_.

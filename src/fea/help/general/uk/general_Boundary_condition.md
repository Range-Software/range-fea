# Гранична умова

**Гранична умова** — це умова, визначена на межі, де межа може бути будь-якою сутністю моделі (точка, лінія, поверхня, об’єм).


Граничні умови:
- **Специфічна задача** - Кожен **Тип задачі** визначає власний набір **граничних умов**.
- **Явний** - точне рішення вказано на межі (наприклад, **Температура** для **Теплопередачі**). Жирний текст у списку **Граничні умови**.
- **Неявне** - передбачає рішення на межі (наприклад, **Тепловий потік** для **Теплопередачі**).


Якщо задача є **перехідною** (залежною від часу), то значення, що залежать від часу, можуть бути призначені граничній умові.

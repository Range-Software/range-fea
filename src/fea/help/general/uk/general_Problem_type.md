# Тип задачі

**Тип задачі** — це унікальний ідентифікатор фізичного явища, яке потрібно вирішити.

Можна комбінувати кілька різних **типів задач** (наприклад, **Теплопередача** та **Аналіз напруги** або **Стислива в’язка течія** та **Дисперсія забруднень**).

Список підтримуваних типів задач:

- дисперсія забруднень
- Електростатика
- Магнітостатика
- В’язка течія, що стискається
- Теплопередача в рідинах
- Теплопередача
- Радіаційний теплообмін
- аналіз напруги
- Модальний аналіз

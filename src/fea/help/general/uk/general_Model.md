# Модель

**Модель** — це віртуальне геометричне зображення тривимірного об’єкта. Модель складається з геометричних **сутностей**.


**Сутність** — це набір елементів (геометричних симплексів) подібного типу, який поділяється на такі типи:

- **Точка** - колекція 0D елементів (вузол).
- **Лінія** - набір 1D елементів (сегмент).
- **Поверхня** - колекція 2D елементів (трикутник, чотирикутник).
- **Об'єм** - колекція 3D елементів (тетраедр, гексаедр).

Незалежно від того, чи є елементи 0D, 1D, 2D або 3D, усі вони представлені в 3D-просторі. Наприклад, точка (вузол) не має розмірів. Він має лише позицію, тоді як лінія має один вимір (довжину).


Кожна **сутність**, крім **Об’єму**, може мати **геометричні** властивості, призначені для повного тривимірного представлення. Це:

- **Точка** - об'єм в кубічних метрах.
- **Лінія** - площа поперечного перерізу в квадратних метрах.
- **Поверхня** - товщина в метрах.

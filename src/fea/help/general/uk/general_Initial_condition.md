# Початкова умова

**Початкова умова** — це умова, визначена на межі, де межа може бути будь-якою сутністю моделі (точка, лінія, поверхня, об’єм) і може розглядатися як початкова точка для розв’язувача. Для **стаціонарних задач** добре вибрана **початкова умова** покращує конвергенцію розв’язувача.

Початкові умови є специфічними для **Задачі**, де кожен **Тип задачі** визначає власний набір **початкових умов**.

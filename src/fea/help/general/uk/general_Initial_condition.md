# Початкова умова

**Початкова умова** — це умова, яку можна задати на будь-якій сутності моделі (Точка, Лінія, Поверхня, Об’єм) і яку можна розглядати як відправну точку для розв’язувача. Для **стаціонарних задач** вдало вибрана **початкова умова** покращує збіжність розв’язувача. Для **нестаціонарних** (залежних від часу) задач вона визначає стан у початковий момент часу.

Початкові умови є специфічними для **задачі**: кожен **тип задачі** визначає власний набір **початкових умов** (наприклад, **Temperature** для **Heat transfer**, **Velocity** і **Pressure** для **Incompressible viscous flow** або **Displacement** для **Stress analysis**).

## Призначення початкової умови

1. Виберіть одну або кілька сутностей у **дереві моделі**.
2. Відкрийте вкладку **Початкові умови** у правій частині головного вікна.
3. Позначте прапорець перед назвою початкової умови, щоб призначити її. Зніміть прапорець, щоб вилучити початкову умову з вибраних сутностей.
4. Виберіть початкову умову, щоб змінити значення її властивостей у списку нижче.

![Початкові умови](image-Initial_conditions.png)

Початкові умови не є обов’язковими. Якщо для певної сутності моделі не задано жодної **початкової умови**, використовується **умова середовища**. На сутностях із **явною граничною умовою** використовується значення, задане граничною умовою.

# Стан середовища

**Умова середовища** — це умова, яку можна вказати в будь-якій сутності моделі, такій як точка, лінія, поверхня або об’єм. **Стан навколишнього середовища** визначає **специфічні значення задачі** для певного середовища (наприклад, **Температура навколишнього середовища** або **Сила гравітації**).


Якщо **Початкова умова** для даної сутності моделі не вказана, тоді використовується **умова середовища**.

# Anfangsbedingung

Eine **Anfangsbedingung** ist eine Bedingung, die am Rand vorgegeben wird, wobei der Rand eine beliebige Modellentität sein kann (Punkt, Linie, Fläche, Volumen). Sie kann als Ausgangspunkt für den Löser betrachtet werden. Bei **stationären Problemen** verbessert eine gut gewählte **Anfangsbedingung** die Konvergenz des Lösers.

Anfangsbedingungen sind **problemspezifisch**: Jeder **Problemtyp** definiert seinen eigenen Satz von **Anfangsbedingungen**.

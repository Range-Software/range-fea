# Umgebungsbedingung

Eine **Umgebungsbedingung** ist eine Bedingung, die auf jeder Modellentität wie Punkt, Linie, Fläche oder Volumen vorgegeben werden kann. Die **Umgebungsbedingung** legt **problemspezifische** Werte für die jeweilige Umgebung fest (z. B. **Umgebungstemperatur** oder **Schwerkraft**).


Ist für eine Modellentität keine **Anfangsbedingung** vorgegeben, wird die **Umgebungsbedingung** verwendet.

# Modell

Ein **Modell** ist eine virtuelle geometrische Darstellung eines dreidimensionalen Objekts. Das Modell besteht aus geometrischen **Entitäten**.


Eine **Entität** ist eine Sammlung von Elementen (geometrischen Simplexen) ähnlichen Typs und wird in folgende Typen unterteilt:

- **Punkt** – Sammlung von 0D-Elementen (Knoten).
- **Linie** – Sammlung von 1D-Elementen (Segmente).
- **Fläche** – Sammlung von 2D-Elementen (Dreiecke, Vierecke).
- **Volumen** – Sammlung von 3D-Elementen (Tetraeder, Hexaeder).

Unabhängig davon, ob die Elemente 0D, 1D, 2D oder 3D sind, werden sie alle im 3D-Raum dargestellt. Ein Punkt (Knoten) hat beispielsweise keine Abmessungen, sondern nur eine Position, während eine Linie eine Abmessung (Länge) hat.


Jeder **Entität** außer dem **Volumen** können **geometrische** Eigenschaften zugewiesen werden, um die 3D-Darstellung zu vervollständigen. Diese sind:

- **Punkt** – Volumen in Kubikmetern.
- **Linie** – Querschnittsfläche in Quadratmetern.
- **Fläche** – Dicke in Metern.

# Randbedingung

Eine **Randbedingung** ist eine Bedingung, die am Rand vorgegeben wird, wobei der Rand eine beliebige Modellentität sein kann (Punkt, Linie, Fläche, Volumen).


Randbedingungen sind:
- **Problemspezifisch** – jeder **Problemtyp** definiert seinen eigenen Satz von **Randbedingungen**.
- **Explizit** – am Rand wird die exakte Lösung vorgeschrieben (z. B. **Temperatur** bei der **Wärmeübertragung**). In der Liste **Randbedingungen** werden sie fett dargestellt.
- **Implizit** – bestimmen die Lösung am Rand indirekt (z. B. **Wärmestrom** bei der **Wärmeübertragung**).


Ist das Problem **transient** (zeitabhängig), können einer Randbedingung zeitabhängige Werte zugewiesen werden.

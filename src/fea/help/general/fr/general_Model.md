# Modèle

Un **modèle** est une représentation géométrique virtuelle d'un objet tridimensionnel. Le modèle est composé d'**entités** géométriques.


Une **entité** est un ensemble d'éléments (simplexes géométriques) de type semblable ; on distingue les types suivants :

- **Point** – ensemble d'éléments 0D (nœuds).
- **Ligne** – ensemble d'éléments 1D (segments).
- **Surface** – ensemble d'éléments 2D (triangles, quadrilatères).
- **Volume** – ensemble d'éléments 3D (tétraèdres, hexaèdres).

Que les éléments soient 0D, 1D, 2D ou 3D, ils sont tous représentés dans l'espace 3D. Par exemple, un point (nœud) n'a pas de dimension, seulement une position, tandis qu'une ligne a une dimension (la longueur).


Des propriétés **géométriques** peuvent être affectées à chaque **entité**, sauf au **volume**, pour compléter sa représentation 3D. Ce sont :

- **Point** – volume en mètres cubes.
- **Ligne** – aire de la section en mètres carrés.
- **Surface** – épaisseur en mètres.

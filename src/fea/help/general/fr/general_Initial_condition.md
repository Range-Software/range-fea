# Condition initiale

Une **condition initiale** est une condition imposée sur la frontière, la frontière pouvant être n'importe quelle entité du modèle (point, ligne, surface, volume) ; elle peut être vue comme un point de départ pour le solveur. Pour les **problèmes stationnaires**, une **condition initiale** bien choisie améliore la convergence du solveur.

Les conditions initiales sont **propres au problème** : chaque **type de problème** définit son propre ensemble de **conditions initiales**.

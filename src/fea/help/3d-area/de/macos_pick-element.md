## Den 3D-Bereich mit einem MacBook-Trackpad bedienen

- **Element markieren:** **⌘ Command** gedrückt halten und auf das Element klicken.
- **Eine Markierung entfernen:** mit derselben Tastenkombination erneut auf das markierte Objekt klicken.
- **Markieren beenden:** die Modifikatortasten loslassen.

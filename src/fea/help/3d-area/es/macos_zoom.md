## Usar el área 3D con el trackpad de un MacBook

- **Zoom:** deslice dos dedos hacia arriba o abajo sin hacer clic. Use el desplazamiento con dos dedos, no el gesto de pellizco. El zoom se centra cerca del puntero.
- **Zoom más rápido:** mantenga **Shift** al desplazarse con dos dedos.
- **Zoom alternativo:** mantenga **Shift + ⌥ Option**, haga clic y arrastre verticalmente.
